# 新手指引

面向第一次使用 **Phoenix 桌面辅助工具（Web 壳）** 的用户。按下面 **四步** 做完即可开始日常 BOM、文件属性与引用管理；可选 **界面巡游** 熟悉布局。

> **文档性质**：本文是**用户上手**说明（点哪里、先做什么），**不是**开发文档。表结构、SQL、迁移规划见 [文档索引](../文档索引.md)（`cad/`、`platform/` 等子目录）。  
> 平台化后，其中部分步骤（如 CAD 扫描）属 **FreeCAD 插件** 清单，壳层通用步骤（配置工作空间、界面巡游）仍由平台提供。

- 一页清单：[快速开始.md](快速开始.md)  
- 壳层布局与 Tab：[Web壳层-使用说明.md](Web壳层-使用说明.md)  
- 启动命令：[web-ui/README.md](../web-ui/README.md)

## 开工四步

### 步骤 1：配置工作空间根（必做）

1. 打开侧栏底部 **配置**（或主页 **新手指南 → 去配置**）。
2. 填写 **工作空间根**（你的 CAD 工程 / 仓库根目录）。
3. 点击 **保存偏好**。

**说明**：必须点保存，路径才会写入本机 `launcher.json` 的「最近工作空间」。仅启动时自带的临时目录不算配置完成。

**未完成时**：侧栏除主页、配置外均为灰色；主页功能卡片不可点。

---

### 步骤 2：填写 FreeCAD 目录（推荐）

仍在 **配置** 页填写 **FreeCAD 目录**（本机安装目录，内含 `freecadcmd` 或 `FreeCAD.app` 等）。

| 场景 | 是否必须填 FreeCAD |
| --- | --- |
| CAD 索引、BOM 列表、文件详情、链接修正、编号查重 | 否 |
| **STEP 批量**（`freecadcmd` 转换） | **是** |

---

### 步骤 3：CAD 索引扫描（必做）

1. 侧栏 **CAD 索引**。
2. 点击 **工程内搜索**（写入 `.phoenix/phoenix-workspace.sqlite`，并重建 BOM 引用表）。
3. 在右侧 **运行日志** 查看进度与结果。

完成后 BOM 列表、文件详情中的 PartKey、类型码、链接标签等才完整。索引语义与「缺失」见 [CAD索引-缺失条目.md](../cad/CAD索引-缺失条目.md)。

**提示**：日常改 XLink 后若未重扫，可在 BOM 列表用 **仅重建引用表**；属性仍以索引为准。

---

### 步骤 4：打开一个文件详情（必做）

1. 点侧栏 `»` 确保 **工作空间树** 已展开。
2. 在树中点击任意 `.FCStd`。

也可在 **BOM 列表** 点击 **链接标签** 列进入同一文件详情。详情页含子 Tab：属性、引用、改名、装配结构等。

## 主页「新手指南」

打开默认 **主页** 可见 checklist：

| 显示 | 含义 |
| --- | --- |
| 圆圈序号 | 未完成 |
| 绿色 ✓ | 已完成（由 API + 本地记录自动判断） |
| **已可开工** | 步骤 1、3、4 均完成 |

每步有快捷按钮（去配置 / 去 CAD 索引 / 展开工作区树）。

---

## 界面巡游（可选）

**前提**：步骤 1 已完成（工作空间已保存）。

1. 主页 **新手指南** → **开始界面巡游**（或 **重新观看界面巡游**）。
2. 按提示依次查看：功能导航 → 配置 → Tab 栏 → 工作区树 → 主内容区 → 运行日志。

巡游前会自动展开右侧树与日志区。也可在 **配置 → 界面** 底部 **重新观看界面巡游**。

## 常见问题

**Q：侧栏点不了 CAD 索引 / BOM？**  
A：请先在配置保存工作空间根。

**Q：BOM 列表很多空属性？**  
A：先完成步骤 3（CAD 索引工程内搜索）。

**Q：STEP 批量按钮灰色？**  
A：在配置填写有效 FreeCAD 目录。

**Q：点树里的 FCStd 没反应？**  
A：确认工作空间已保存且树已加载；若当前页是 BOM 等，可能由该页接管选择，否则应打开文件详情。

**Q：巡游找不到高亮区域？**  
A：先点「开始界面巡游」；若仍异常，加宽导航栏（点 `▶`）并展开右侧栏 `»`。

**Q：换了一台电脑进度还在吗？**  
A：清单中「打开文件详情」与巡游记录存在浏览器 `localStorage`；工作空间/索引状态以本机 launcher 与 `.phoenix` 为准。
