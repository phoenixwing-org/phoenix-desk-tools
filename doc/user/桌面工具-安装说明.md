# 安装说明

源码：<https://gitee.com/PhoenixWing321/phoenix-desk-tools.git>

**环境要求**：Python 3.10+；Node.js + **pnpm**（如需前端开发／构建）。

## 1. 克隆与 Python 依赖

在仓库根目录：

```bash
git clone https://gitee.com/PhoenixWing321/phoenix-desk-tools.git
cd phoenix-desk-tools
```

### Windows 一键初始化（推荐）

PowerShell 或 cmd 在仓库根执行：

```bat
scripts\setup_dev.bat
```

等价于：`powershell -ExecutionPolicy Bypass -File scripts\setup_dev.ps1`

脚本会创建 `.venv-desktop`、安装 `pip install -e ".[web]"`、`pnpm install`。可选参数：

| 参数 | 说明 |
| --- | --- |
| `-SolidWorks` | 额外安装 `windows-solidworks`（pywin32） |
| `-SkipPnpm` | 仅 Python 侧，跳过 Node/pnpm |
| `-RecreateVenv` | 删除已有虚拟环境后重建 |

### 手动安装

```bash
python -m venv .venv-desktop
```

激活虚拟环境：

| 系统 | 命令 |
| --- | --- |
| Windows (PowerShell) | `.venv-desktop\Scripts\Activate.ps1` |
| Windows (cmd) | `.venv-desktop\Scripts\activate.bat` |
| macOS / Linux | `source .venv-desktop/bin/activate` |

然后安装 Python 包（含 Web API）：

```bash
python -m pip install -U pip
pip install -e ".[web]"
```

Windows 上若需 **SolidWorks / pywin32** 可选能力：`pip install -e ".[web,windows-solidworks]"`。

## 2. Node.js 与 pnpm

`python -m phoenix.web --dev` **仅启动 API**（热更新 :8765），前端已分离至 pnpm 管理，但仍需安装 **Node.js**（建议 **LTS**，≥ 18）和 **pnpm** 来运行前端或构建。

### 安装 Node.js

| 系统 | 方式 |
| --- | --- |
| **Windows** | [nodejs.org](https://nodejs.org/) 下载 LTS 安装包；或 [nvm-windows](https://github.com/coreybutler/nvm-windows) 管理多版本 |
| **macOS** | [nodejs.org](https://nodejs.org/) 安装包，或 `brew install node` |
| **Linux** | 发行版包管理器，或 [nodejs.org](https://nodejs.org/) |

安装后新开终端验证：

```bash
node -v    # 例如 v22.x
npm -v
```

### 安装 pnpm

任选一种（Node 16.13+ 推荐第一种）：

```bash
corepack enable
corepack prepare pnpm@latest --activate
```

或：

```bash
npm install -g pnpm
```

验证：`pnpm -v`

## 3. 前端依赖

**使用前端（开发模式 `pnpm dev`／日常构建 `--build`）必须先执行**：

```bash
pnpm install    # 在仓库根目录；依赖装在 web-ui/
```

若报错 `Cannot find module ... vite`，说明尚未执行本步或安装不完整，重新 `pnpm install` 即可。

## 4. 启动

```bash
python -m phoenix.web --dev    # 开发：仅 API 热更新 (:8765)，前端需另启 pnpm dev
python -m phoenix.web          # 日常：需已有 web-ui/dist，或加 --build
python -m phoenix              # 可选启动器：选工作空间后打开 Web（需 tkinter）
```

`-w /path/to/CAD/workspace` 可指定工作空间；省略则读最近记录。

**仅 Web 开发**（`pnpm dev`）时步骤 1 的 `[web]`、步骤 2 的 Node.js/pnpm、步骤 3 的 `pnpm install` 缺一不可；仅需 API 可跳过 Node.js/pnpm；不必单独装 tkinter。

**桌面启动器**（`python -m phoenix`）额外需要带 **tkinter** 的 Python。macOS 可执行 `bash scripts/setup_desktop_venv.sh`；Windows 用上方 `setup_dev.bat` 后若缺 tkinter，请安装 [python.org](https://www.python.org/downloads/) 并勾选 tcl/tk。

功能与配置见 [桌面工具-使用说明.md](桌面工具-使用说明.md) · 前端细节见 [web-ui/README.md](../../web-ui/README.md)。
