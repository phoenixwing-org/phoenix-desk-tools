# Web 壳层 — 使用说明

浏览器中的 **Phoenix 桌面辅助工具** 界面（Vue3 + Element Plus + Python API）。首次使用请先读 [新手指引.md](新手指引.md) 或 [快速开始.md](快速开始.md)。

启动方式见 [web-ui/README.md](../web-ui/README.md)。壳层改型规划见 [Web壳层-Ribbon改型-规划.md](../platform/Web壳层-Ribbon改型-规划.md)。

---

## 1. 布局（WPS 式 Ribbon）

```
┌─ 顶栏（40px）────────────────────────────────────────────────────────────┐
│ [Phoenix / 工作空间名] │ 系统 CAD Code │ ← 页面 Tab（图标+标题）→ │ ▲ │
├─ Ribbon 工具条（约 66px，可 ▲ 折叠；切换功能区 Tab 时自动展开）──────────┤
│  大图标工具（组间竖线）│「系统」：工作空间 comb / 模块纵排 │ 各 Tab 右侧：树/属性/日志/侧栏 │
├─ 主内容区 ─────────────────────────────────────│ 工作空间树（左/右）       │
│  当前 Tab 对应的功能页 / 文件详情 / …           ├──────────────────────────┤
│                                                │ 属性 / 运行日志（同侧可拖）│
├────────────────────────────────────────────────┴──────────────────────────┤
│ 状态栏 │ 右侧：树 / 属性 / 日志 / 工作集 / 侧栏停靠 图标（悬停 tooltip）   │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 作用 |
| --- | --- |
| **欢迎页** | 启动默认全屏；最近工程、Gitee 链接；点击工程进入工作台。不在 Tab 栏中 |
| **顶栏品牌** | 点击整块 **Phoenix** 返回欢迎页；副标题显示当前工作空间名（悬停看完整路径） |
| **功能 Tab** | 顶栏分段导航：**系统 / CAD / Code**（系统置首）；切换后下方 Ribbon 显示对应工具；若 Ribbon 已折叠则**自动展开** |
| **页面 Tab** | 顶栏**中部居中**托盘：已打开页；左侧 **与 Ribbon 相同的 page 图标**；当前 Tab **略大 + 切换动画**；× 关闭；右侧 **全部关闭** / **新建 Tab** |
| **Ribbon** | 当前 Tab 下 **大图标**工具；**系统** Tab 另含主页/配置/单元测试、工作空间 comb、模块纵排、侧栏操作 |
| **主内容区** | 当前 Tab 页面（KeepAlive 保留状态） |
| **工作空间树** | 浏览 FCStd 等；与日志可同侧或分列左右；**左右侧栏宽度分别持久化**（`left_panel_width_px` / `right_panel_width_px`） |
| **运行日志** | 扫描、批量任务输出；与树**同侧**时中间横条可**上下拖拽**（上树下日志，高度 `log_panel_height_px` 持久化） |
| **页脚面板** | 右侧图标切换树 / 属性 / 日志 / 工作集 / 侧栏停靠（与 Ribbon 右侧壳层区同步；悬停见 tooltip） |
| **浏览器标题** | `Phoenix 桌面工具 - {工作空间}`；打开功能页后追加 `· {当前页}` |
| **页内 ?** | 多数功能页标题旁：本页要点弹层；有步骤的页可 **本页导引**（driver.js） |

左侧 **28px 快捷栏**（新手指引 / 配置 / 树开关）默认隐藏，代码保留于 `NavSidebar.vue` 待用。

## 2. 欢迎页、主页与配置

| 入口 | page id | 说明 |
| --- | --- | --- |
| **欢迎页** | `welcome` | 全屏；最近工程、打开工作空间、新手指南 / Gitee 链接 |
| **主页** | `home` | 新手指南四步清单、**功能模块**勾选、功能入口卡片；需从 Ribbon「主页」或欢迎页进入 |
| **配置** | `config` | 工作空间根、FreeCAD、最近打开、**界面**（侧栏停靠、图标大小）、Web 服务；Ribbon **系统 → 配置** 或欢迎页打开 **Modal** |

工作空间须在配置中 **保存偏好** 后，才会记入 launcher 最近列表并解锁其它功能（见 [新手指引.md](新手指引.md) § 门禁）。

## 3. Tab 与工作台

- 单页功能（如 CAD 索引、Code 索引）默认 **1 个 Tab**；Ribbon 再次点击会激活已有 Tab，不重复打开。
- **文件详情**、**零件详情** 等支持 **多 Tab**（上限见 `app_config.json` → `workbench.pages`）。
- 同一文件路径或同一 PartKey **复用**已有 Tab。
- **主页**、**欢迎页** 默认不出现在顶栏页面 Tab 中（主页由入口打开；欢迎页为全屏态）。
- 刷新浏览器后，Tab 列表与部分页面状态可从服务端会话恢复（`workbench_session`）。
- **地址栏同步**：导航时自动写入 `?page=…`（欢迎页为 `?view=welcome`）。
- **F5 / 深度刷新**（同标签 `Cmd+Shift+R`）：优先读 **sessionStorage** 恢复 Tab 列表，再按地址栏激活对应页；侧栏停靠等读 launcher，不依赖 URL。
- **新开标签** 打开带 `?page=` 的链接：无 session 时按 URL 打开页面。

讨论稿：[Web壳层-Tab与状态持久化-规划讨论.md](../platform/Web壳层-Tab与状态持久化-规划讨论.md)。

## 4. Ribbon 使用要点

1. **选功能区**：顶栏点 **系统 / CAD / Code**；若 Ribbon 已折叠会自动展开。
2. **开功能**：点击下方 Ribbon 按钮 → 打开或激活对应页面 Tab。
3. **系统 Tab**：**主页 / 配置 / 单元测试**；**工作空间** comb、**模块** 纵排（仅系统 Tab）。
4. **壳层快捷**：任意 Tab 的 Ribbon **最右侧**可开 **树 / 属性 / 日志 / 侧栏**（与页脚等效）；**分组**为大图标，**单行**为紧凑横排。
5. **折叠**：顶栏右侧 **▲** 隐藏 Ribbon 面板，仅保留功能 Tab 行。
6. **布局**：Ribbon 最右侧 **单行 / 分组** 切换；**分组**为大图标（默认），**单行**为紧凑横排。
7. **模块过滤**：主页取消勾选某模块后，对应 Ribbon Tab 与工具隐藏；当前页会被切回主页。

配置表：`web-ui/src/layout/ribbon/ribbonConfig.ts`（静态分组；标签可覆盖 `navigation.label`）。

## 5. 工作空间树与文件详情

1. 在配置中保存有效 **工作空间根**。
2. 侧栏树加载目录；按当前模块偏好筛选 FCStd / `.cpp` 等。
3. 点击 `.FCStd`：
   - 若当前 Tab 注册了树选择处理（如 BOM 列表选装配），由该页接管；
   - 否则 **默认打开文件详情**（属性 / 引用 / 改名等子 Tab）。

树上方搜索框可按路径片段过滤。树、日志 **左/右停靠** 在 **系统 → 侧栏** 或 配置 → **界面** 中设置。树与日志**同侧**时，中间分隔条可上下拖拽调节日志高度（写入 `launcher.json` → `shell_layout.log_panel_height_px`）；左右侧栏**各自**宽度为 `left_panel_width_px` / `right_panel_width_px`。

## 6. 新手指南与门禁（摘要）

| 规则 | 行为 |
| --- | --- |
| 未保存工作空间 | 仅 **欢迎页**、**主页**、**配置** 可进；Ribbon 其它工具灰色 |
| 未填 FreeCAD | 多数功能仍可用；**STEP 批量** 的预览/转换不可用 |
| 未做 CAD 索引 | **BOM 列表** 顶栏提示先去 **CAD 索引**（Ribbon → CAD） |
| 界面巡游 | 工作空间就绪后，主页或配置中启动（driver.js，约 6 步：功能 Tab / Ribbon / 页面 Tab / 树 / 主内容 / 日志） |

清单完成状态：`GET /api/onboarding/status` + 浏览器 `localStorage`（详见 [新手指引-实现备忘.md](新手指引-实现备忘.md)）。

### 7.1 单元测试页（系统）

- **运行范围**：勾选 Code / CAD / 平台 套件；点 **列出运行范围** 展开模块表，可**按模块勾选**（默认全选，部分选中时仅跑勾选的模块）。
- **失败关注**：失败/错误记入浏览器 localStorage；可排序、勾选复测、从列表移除。
- 不依赖工作空间；结果区「套件 / 状态」筛选仅影响展示，与运行范围无关。

### 7.2 文件工作集（侧栏 · 工作集）

- 侧栏 **工作集** Tab：命名 path 集合；Code 索引 / 工作空间树可 **加入当前工作集**。
- Code UUID 等页通过 **WorksetScopePicker** 限定扫描范围；详见 [FileWorkset-规划.md](../platform/FileWorkset-规划.md)。

## 8. 路径显示

配置页路径为 **绝对路径**；各功能页内多为相对工作空间根的 `./…` 展示。规则见 [路径与目录显示约定.md](../路径与目录显示约定.md)。

## 9. 与桌面启动器的关系

`python -m phoenix` 桌面窗口仅用于选工作空间、打开浏览器；**功能均在 Web 壳** 完成，与本节描述一致。
