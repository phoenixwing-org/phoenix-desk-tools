# Web 壳层 — 使用说明

浏览器中的 **Phoenix 桌面辅助工具** 界面（Vue3 + Element Plus + Python API）。首次使用请先读 [新手指引.md](新手指引.md) 或 [快速开始.md](快速开始.md)。

启动方式见 [web-ui/README.md](../web-ui/README.md)。壳层改型规划见 [Web壳层-Ribbon改型-规划.md](../platform/Web壳层-Ribbon改型-规划.md)。

---

## 1. 布局（Chili3D 式 Ribbon）

```
┌─ 顶栏（40px）────────────────────────────────────────────────────────┐
│ [Phoenix] │ 🏠 ⚙ │ 开始 CAD Code 系统 │ ← 页面 Tab → │ CAD Code │ 工作空间… │
├─ Ribbon 工具条（约 44～58px，可 ▲ 折叠）──────────────────────────────┤
│  分组工具按钮（单行 / 分组两种布局，右侧可切换）                        │
├─ 主内容区 ─────────────────────────────────────│ 工作空间树（左/右）   │
│  当前 Tab 对应的功能页 / 文件详情 / …           ├──────────────────────┤
│                                                │ 运行日志（左/右）     │
├────────────────────────────────────────────────┴──────────────────────┤
│ 状态栏                                                                │
└───────────────────────────────────────────────────────────────────────┘
```

| 区域 | 作用 |
| --- | --- |
| **欢迎页** | 启动默认全屏；最近工程列表、Gitee 链接；点击工程进入工作台。不在 Tab 栏中 |
| **顶栏品牌** | 点击整块 **Phoenix** 返回欢迎页；🏠 同效 |
| **功能 Tab** | **开始 / CAD / Code / 系统**：切换后下方 Ribbon 显示对应模块工具 |
| **页面 Tab** | 顶栏中部：已打开的功能页与文件详情；× 关闭单个；**全部关闭** 后回到欢迎页 |
| **Ribbon** | 当前功能 Tab 下的工具按钮；**▲/▼** 折叠以腾出主内容高度；**单行/分组** 布局偏好保存在浏览器 |
| **模块 chip** | 顶栏右侧 **CAD / Code**：启用哪些模块（与主页「功能模块」勾选同步） |
| **工作空间 pill** | 当前工程根目录摘要；▼ 最近列表 |
| **主内容区** | 当前 Tab 页面（KeepAlive 保留状态） |
| **工作空间树** | 浏览 FCStd 等；停靠左或右（顶栏 **侧栏** 按钮或 配置 → 界面） |
| **运行日志** | 扫描、批量任务输出；与树可同侧或分列左右；停靠与日志是否展开无关，随时可改 |
| **页内 ?** | 多数功能页标题旁：本页要点弹层；有步骤的页可 **本页导引**（driver.js） |

左侧 **28px 快捷栏**（新手指引 / 配置 / 树开关）默认隐藏，代码保留于 `NavSidebar.vue` 待用。

## 2. 欢迎页、主页与配置

| 入口 | page id | 说明 |
| --- | --- | --- |
| **欢迎页** | `welcome` | 全屏；最近工程、打开工作空间、新手指南 / Gitee 链接 |
| **主页** | `home` | 新手指南四步清单、**功能模块**勾选、功能入口卡片；需从 Ribbon「主页」或欢迎页进入 |
| **配置** | `config` | 工作空间根、FreeCAD、最近打开、**界面**（侧栏停靠、图标大小）、Web 服务；顶栏 ⚙ 以 **Modal** 打开 |

工作空间须在配置中 **保存偏好** 后，才会记入 launcher 最近列表并解锁其它功能（见 [新手指引.md](新手指引.md) § 门禁）。

## 3. Tab 与工作台

- 单页功能（如 CAD 索引、Code 索引）默认 **1 个 Tab**；Ribbon 再次点击会激活已有 Tab，不重复打开。
- **文件详情**、**零件详情** 等支持 **多 Tab**（上限见 `app_config.json` → `workbench.pages`）。
- 同一文件路径或同一 PartKey **复用**已有 Tab。
- **主页**、**欢迎页** 默认不出现在顶栏页面 Tab 中（主页由入口打开；欢迎页为全屏态）。
- 刷新浏览器后，Tab 列表与部分页面状态可从服务端会话恢复（`workbench_session`）。
- **地址栏同步**：导航时自动写入 `?page=…`（欢迎页为 `?view=welcome`）。
- **F5 / 深度刷新**（同标签 `Cmd+Shift+R`）：优先读 **sessionStorage** 恢复 Tab 列表，再按地址栏激活对应页；侧栏停靠等读 launcher，不依赖 URL。
- **新开标签** 打开带 `?page=` 的链接：无 session 时按 URL 打开页面。

讨论稿：[Web壳层-Tab与状态持久化-规划讨论.md](../platform/Web壳层-Tab与状态持久化-规划讨论.md)。

## 4. Ribbon 使用要点

1. **选模块**：顶栏点 **CAD** 或 **Code**（或 **开始** / **系统**）。
2. **开功能**：点击下方 Ribbon 按钮 → 打开或激活对应页面 Tab。
3. **折叠**：顶栏右侧 **▲** 隐藏 Ribbon 面板，仅保留功能 Tab 行。
4. **布局**：Ribbon 右侧 **单行 / 分组** 切换；单行时按钮横向排列、按文字自适应宽度。
5. **模块过滤**：主页取消勾选某模块后，对应 Ribbon Tab 与工具隐藏；当前页会被切回主页。

配置表：`web-ui/src/layout/ribbon/ribbonConfig.ts`（静态分组；标签可覆盖 `navigation.label`）。

## 5. 工作空间树与文件详情

1. 在配置中保存有效 **工作空间根**。
2. 侧栏树加载目录；按当前模块偏好筛选 FCStd / `.cpp` 等。
3. 点击 `.FCStd`：
   - 若当前 Tab 注册了树选择处理（如 BOM 列表选装配），由该页接管；
   - 否则 **默认打开文件详情**（属性 / 引用 / 改名等子 Tab）。

树上方搜索框可按路径片段过滤。树、日志 **左/右停靠** 在配置 → **界面** 中分别设置。

## 6. 新手指南与门禁（摘要）

| 规则 | 行为 |
| --- | --- |
| 未保存工作空间 | 仅 **欢迎页**、**主页**、**配置** 可进；Ribbon 其它工具灰色 |
| 未填 FreeCAD | 多数功能仍可用；**STEP 批量** 的预览/转换不可用 |
| 未做 CAD 索引 | **BOM 列表** 顶栏提示先去 **CAD 索引**（Ribbon → CAD） |
| 界面巡游 | 工作空间就绪后，主页或配置中启动（driver.js，约 6 步：功能 Tab / Ribbon / 页面 Tab / 树 / 主内容 / 日志） |

清单完成状态：`GET /api/onboarding/status` + 浏览器 `localStorage`（详见 [新手指引-实现备忘.md](新手指引-实现备忘.md)）。

## 9. 与桌面启动器的关系

`python -m phoenix` 桌面窗口仅用于选工作空间、打开浏览器；**功能均在 Web 壳** 完成，与本节描述一致。
