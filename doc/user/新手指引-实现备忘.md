## 1. API

### `GET /api/onboarding/status`

实现：`phoenix/services/onboarding_service.py` · 路由：`phoenix/web/app.py`

**响应示例**

```json
{
  "workspace_ok": true,
  "workspace_path": "/path/to/repo",
  "freecad_ok": true,
  "index_scanned": true,
  "last_scan_at": "2026-06-02T12:00:00"
}
```

| 字段 | 判定逻辑 |
| --- | --- |
| `workspace_ok` | 路径为可读目录，且 `resolve` 后与 launcher **最近工作空间** 中某条一致（用户曾 **保存偏好**）；临时目录不计入最近列表 |
| `freecad_ok` | `launcher.freecad_dir` 非空且为目录 |
| `index_scanned` | `load_fcstd_map_payload` 的 `last_scan_at` 非空，或 `stats.total_entries > 0` |

`opened_file_detail` **仅前端**维护（见 §2）。

单元测试：`tests/test_onboarding_service.py`。

## 2. 前端存储（Pinia + localStorage）

**Store**：`web-ui/src/stores/onboarding.ts`  
**键名**：`phoenix-onboarding-v1`

```json
{
  "tourVersionSeen": 1,
  "openedFileDetailByWorkspace": {
    "/path/to/repo": true
  }
}
```

| 数据 | 来源 |
| --- | --- |
| `workspace_ok` / `freecad_ok` / `index_scanned` | `refreshStatus()` → API |
| `openedFileDetail` | `markFileDetailOpened(ws)`；`syncFileDetailFromTabs` 扫描 Tab 的 `file_detail` / `bom_apply` |
| `shellTourDone` | `tourVersionSeen >= SHELL_TOUR_VERSION` |

切换工作空间后按 `workspace_path` 分桶判断步骤 4，避免误显示已完成。

## 4. 门禁策略

| 类型 | 页面 / 行为 | 规则 |
| --- | --- | --- |
| 始终允许 | `home`, `config`, `welcome` | — |
| 工作空间硬门禁 | 其它 `goToPage`、主页功能卡、Ribbon 工具 | `!workspace_ok` → 跳转配置 + 状态栏提示 |
| FreeCAD 软 + 任务硬门禁 | `step_batch` 预览/运行 | `!freecad_ok` → 按钮禁用 + `OnboardingBanner` |
| 索引软引导 | `bom_export` | 横幅 + 文案，不拦进入 |

`openFileDetailForRel` / `openPartKeyDetail` 内部调用 `requireWorkspace()`。

**首次未配置**：`init()` 在 `restoreWorkbenchSession` 后若无 `workspace_ok`，打开 `home` + `config` Tab。

## 5c. BOM 物化路径（`bom_tree_occurrence`）

| 表 | 作用 |
| --- | --- |
| `bom_xref` | 直接边：宿主 → 子件（查 **直接** 入向：`target_repo_rel_path`） |
| `bom_tree_occurrence` | 各总成 **full 树** 压平行：`root` + `tree_path`（如 `1.2.3`）+ 父子路径 |
| `bom_assembly_cache` | 单总成装配树 JSON 缓存（文件详情用） |

重建引用表时：`replace_bom_xrefs` → `rebuild_bom_tree_occurrences`（按总成列表展开 full 树并 INSERT）。

`GET /api/bom-xrefs/usage-stats?rel=`：返回 `direct_incoming_host_count`、`bom_occurrence_count`（树中出现次数）、`occurrences[]`（根总成 + 物化路径）。

总成列表 SQL 子查询：`incoming_host_count` = 直接引用该总成文件的宿主数。
