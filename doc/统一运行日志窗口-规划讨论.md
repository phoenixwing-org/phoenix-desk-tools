# 统一运行日志窗口 — 规划讨论

> 状态：**已实现**（Web + 桌面壳）  
> 关联：[web界面.md](web界面.md)、[Web与桌面迁移-待办.md](Web与桌面迁移-待办.md)

---

## 1. 现状

| 层级 | 单行摘要 | 多行运行日志 |
| --- | --- | --- |
| **Web** | `useAppShell().setStatus()` → 底栏 `StatusBar` | 各页自建 `logText` + 页内 `<pre class="log">`（STEP 批量、XLink、FCStd 索引、SW→STEP 等） |
| **桌面 Tk** | `AppShell._render_status_bar()` | 各页自建 `CTkTextbox _log` + `_log_line()`；`BasePage.append_log` 仅写 `state.last_log`，**未统一展示** |

问题：

- 日志位置、样式、是否自动展开 **每页各一套**；
- 长任务（freecadcmd、COM 导出）输出在页面中部，切页后看不见；
- 底栏 `setStatus` 与页内 log **职责重叠**（一行摘要 vs 全文）。

---

## 2. 目标

1. **壳层唯一日志区**：各功能子页只调用统一 API，不再各自维护大块 `<pre>` / `Textbox`。
2. **位置**：**右侧栏下方**（与工作空间树同列，树上 / 日志下），可 **纵向拖拽** 调节高度。
3. **可关闭**；有 **新日志** 时按策略 **自动展开**（可配置，默认开）。
4. **Web / 桌面** 语义一致，偏好写入 launcher `shell_layout`（与右栏宽度同级）。

---

## 3. 布局（推荐）

右栏改为 **上下分割**（Web：CSS flex + 横向 sash 已有，新增 **纵向 sash**；桌面：右侧 `CTkFrame` 内嵌 `Panedwindow(vertical)` 或等价实现）：

```
┌──────────┬──────────────────┐
│          │  工作空间树       │
│  导航    │  ─── sash ───     │  ← 可拖
│          │  运行日志  [×][清空]│
│  主页面   │  (monospace)      │
│          │                   │
└──────────┴──────────────────┘
│ 状态栏：一行摘要              │
└───────────────────────────────┘
```

- 右栏整体仍用现有 **横向 sash**（主内容 ↔ 右栏）调节宽度。
- 日志区 **最小高度 ~80px**，默认 **~180px**，最大不超过右栏高度的 ~70%。
- 右栏关闭时，日志一并隐藏；可选：右栏关闭后仍允许从工具条/快捷键 **仅弹出日志**（P2，非必须）。

**不推荐** P0 做全局右下角浮层：与工作空间树争位置，且难与「右栏关闭」状态一致。

## 4. 统一 API（信号）

### 4.1 职责划分

| API | 用途 | 展示位置 |
| --- | --- | --- |
| **`setStatus(msg)`** | 一行摘要（完成、计数、路径） | 底栏（保持） |
| **`appendLog(text, opts?)`** | 多行过程 / 命令输出 / 错误栈 | 右侧日志窗 |
| **`clearLog()`** | 新任务开始前清空 | 日志窗 |
| **`setLogOpen(open)`** | 用户点 × 或菜单 | 日志窗 + 持久化 |

`setStatus` **不**再重复粘贴整段 freecadcmd 输出；详情只进 `appendLog`。

### 4.2 Web（`useAppShell` 扩展草案）

```ts
type LogAppendOptions = {
  clear?: boolean;       // 先清空再写
  open?: boolean;        // true=强制展开；false=仅追加不展开；默认遵循 auto_open
  source?: string;       // 可选前缀，如 "step_batch"
};

appendLog(text: string, opts?: LogAppendOptions): void;
clearLog(): void;
setLogOpen(open: boolean): void;

// 只读
logLines: Ref<string>;           // 或单一 logText，换行拼接
logPanelOpen: Ref<boolean>;
logPanelHeightPx: Ref<number>;
```

实现要点：

- `appendLog` 末尾 `\n` 规范化；可选 **最大行数**（如 5000 行）防止内存膨胀。
- **`log_auto_open_on_append`**（默认 `true`）：关闭状态下首次 `appendLog` 自动 `setLogOpen(true)`。
- 用户手动关闭后，同页 **连续追加** 是否再次自动打开 → 建议 **本会话内不再自动弹**（直到切换页面或点「运行」且 `clear:true`）。

### 4.3 桌面（壳层回调）

```python
# fcdesk/shell/log_panel.py 或 AppShell 方法
def shell_append_log(
    self,
    text: str,
    *,
    clear: bool = False,
    open_panel: bool | None = None,
    source: str | None = None,
) -> None: ...

def shell_clear_log(self) -> None: ...
def shell_set_log_open(self, open: bool) -> None: ...
```

各页 `_log_line` 改为 `self.shell_append_log(...)`（`BasePage` 注入 `log_fn` 或持有 `AppShell` 弱引用）。

后台线程仍 `after(0, lambda: shell_append_log(...))`，与现 STEP 批量一致。

## 5. 持久化（launcher `shell_layout`）

在现有字段上扩展（Web PATCH `/api/config/launcher/shell-layout` 已有）：

```json
{
  "nav_rail_mode": 1,
  "right_panel_open": true,
  "right_panel_width_px": 300,
  "mid_right_sash_px": null,
  "log_panel_open": true,
  "log_panel_height_px": 180,
  "log_auto_open_on_append": true
}
```

- 日志 **内容** 不持久化（刷新/重启清空）；仅 UI 开合与高度。
- 切换工作空间 **不清** 日志（便于对照）；切换功能页 **默认保留** 日志，标题区显示 `来源: STEP 批量`（P1）。

## 6. 日志窗 UI

| 元素 | 行为 |
| --- | --- |
| 标题 | 「运行日志」+ 可选来源页 |
| **×** | 关闭面板（`log_panel_open=false`） |
| **清空** | `clearLog()` |
| **复制** | 复制全部（P1） |
| 正文 | `pre` / `Textbox`，只读，`Menlo` 等等宽字体 |
| 纵向 sash | 拖曳改变 `log_panel_height_px` |

有未读日志且面板关闭时，标题旁 **小圆点** 或 sash 处高亮（P2）。

## 7. 各页迁移顺序

| 阶段 | 页面 | 说明 |
| --- | --- | --- |
| **L0** | 壳层 + API | `LogPanel.vue` / 桌面 `LogPanelFrame`；`shell_layout` 字段 |
| **L1** | STEP 批量、SW→STEP | 长任务、已有 log 块，收益最大 |
| **L2** | XLink、FCStd 索引 | 命令输出 |
| **L3** | 零件去重、属性回写 | 扫描摘要 / 长输出 |
| **L4** | 桌面各页 `_log` 删除 | 与 Web 对齐 |

每页改动模式：

```ts
// Before
logText.value = data.log;
shell.setStatus(`成功 ${n} …`);

// After
shell.clearLog();
shell.appendLog(data.log, { clear: true, source: "step_batch" });
shell.setStatus(`成功 ${n} · 详见运行日志`);
```

---

## 8. 与流式 / 长任务

P0：**任务结束一次性** `appendLog(整段)`（与现 API 一致）。

P1（可选）：`appendLog` 支持增量；WebSocket 或轮询 job id（STEP 批量、扫描）→ 壳层 `appendLog(line, { open: false })` 节流刷新。

## 9. 不在范围内

- 写磁盘日志文件（需要另开「导出日志」）；
- 替代 XLink 等任务的 Markdown 报告；STEP 批量明细默认进运行日志（可选 `FCD_BATCH_WRITE_REPORT=1` 落盘）。
- 替换 SQLite / `.phoenix` 审计。
