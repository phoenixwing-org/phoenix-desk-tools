# 调试输出配置 — 设计讨论

## 1. 设置页改为 Page 模式

### 现状
设置页 (`ConfigPage.vue`) 是普通页面，可打开多个 Tab。

### 目标
- 设置页只允许打开一个实例（Page 模式）
- 内部加 TabPage 子导航

### 实现方式

`app_config.json` 的 `page_context_config` 已有 `max_tabs` 控制：

```json
"config": { "max_tabs": 1 }   // ← 已有字段，设 1 即可
```

设置页内 TabPage 参考 `FileDetailPage.vue` 的 `activeSubTab` 模式：
- "工作空间" tab
- "FreeCAD" tab  
- "调试输出" tab（新增）

### 可行性：✅ 已有基础设施，改配置 + 加组件即可。

## 2. 调试输出开关

### 需求
- 每个模块/页面可独立开关调试输出
- 默认全关
- 配置持久化到 `~/.phoenix/launcher-prefs.json`（复用已有文件，不新建）
- 服务启动时加载到内存 Map
- 运行时 O(1) 判断

### 数据模型

```json
// ~/.phoenix/launcher-prefs.json 新增字段
{
  "recent_workspaces": [...],
  "freecad_dir": "...",
  "debugConfig": {
    "cad/bom_viewer": true,
    "cad/*": false,
    "code/*": false,
    "system/*": false
  }
}
```

### 内存结构

```typescript
// server/src/lib/pdtDebugConfig.ts
const debugMap = new Map<string, boolean>();

export function loadDebugConfig() {
  const prefs = loadPrefs(); // 复用 shell.ts 的 loadPrefs
  const cfg = prefs.debugConfig || {};
  for (const [k, v] of Object.entries(cfg)) debugMap.set(k, v as boolean);
}

export function isDebugEnabled(module: string, page: string): boolean {
  return debugMap.get(`${module}/${page}`) ?? debugMap.get(`${module}/*`) ?? false;
}
```

### API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/config/launcher/debug` | 获取调试配置 |
| PUT | `/api/config/launcher/debug` | 更新单条 `{module, page, enabled}` |

### 前端 UI

设置页新增「调试输出」TabPage，表格：

| 模块 | 页面 | 输出 |
|------|------|------|
| cad | bom_viewer | ☐ |
| cad | part_catalog | ☐ |
| cad | * (全部) | ☐ |
| code | * (全部) | ☐ |
| caa | * (全部) | ☐ |
| system | shell | ☐ |

### 后端使用

```typescript
// cad.ts 中
import { isDebugEnabled } from "../lib/pdtDebugConfig";
if (isDebugEnabled("cad", "bom_viewer")) {
  console.log("[cad-rust]", details);
}
```

## 3. 存储选择

**复用 `~/.phoenix/launcher-prefs.json`**，不新建文件。

- ✅ 已有 loadPrefs/savePrefs 基础设施（shell.ts）
- ✅ JSON 读写足够（调试配置是简单键值对，不需要 SQL）
- ✅ 不新增依赖
- ✅ 随启动器偏好一起持久化

4. **文档**：更新 README

## 5. 可行性结论

全部可行。基础设施已有：
- ✅ `max_tabs: 1` 限制单实例
- ✅ `PnwDbAdapter` SQLite 持久化
- ✅ Hono 路由添加 API
- ✅ Element Plus 表格组件

**风险**：调试输出可能影响性能（每个 log 都查 Map）。缓解：Map 查找 O(1)，影响可忽略。

**建议**：先实现后端 + 前端 UI，逐步在关键模块（cad.ts、shell.ts、unit-tests）接入。
