# CAD 索引面板人工点检清单

> 适用范围：Phoenix Desk Tools 0.2.x 的“CAD 索引 → 索引列表”。
>
> 目标：验证列表拆成 `FcstdMapIndexPane` 后，搜索、筛选、分页、打开动作、空状态以及横纵滚动仍保持原行为。
>
> 本清单只验收 Web UI；Windows 安装包、FreeCAD/SolidWorks 外部进程不在本次范围。

## 1. 结果约定与准备

每项填写“通过 / 失败 / 跳过”。失败时记录窗口大小、页面截图、运行日志和缺陷编号，不要只写“滚动不工作”。

准备一个可安全扫描的 Git 工作区，样本至少包含：

- 30 条以上索引记录，确保 20 条分页下能够翻页；
- `present` 与 `missing` 两种状态；
- FCStd、Markdown、PDF 中至少两种资产类型；
- 至少一个带完整 `PartNumber.PartVersion` 的条目；
- 至少一个可打开的 `present` FCStd，以及一个不可打开的 `missing` 条目。

建议留证：

```bash
git rev-parse HEAD
git status --short
```

- [ ] 打开“CAD 索引”，进入“索引列表”
- [ ] 点击“工程内搜索”后有 30 条以上可用样本
- [ ] 记录浏览器版本、窗口宽高和当前提交

## 2. 正常宽度与压缩高度滚动

先使用约 760px 的列表可用宽度，再缩短窗口高度，使一页数据无法完整显示。

- [ ] 搜索栏、两组筛选和数量摘要始终可见，没有被表格覆盖
- [ ] 数据超出可用高度时，垂直滚动只出现在表格内部
- [ ] 滚动到末行后能看到当前页最后一条数据
- [ ] 垂直滚动时十二列表头保持吸顶，表头文字不随数据离开
- [ ] 分页器保持在表格下方，不被末行遮住，也不随表格内容滚走
- [ ] 十二列超出宽度时，表格内部出现横向滚动
- [ ] 横向滚到“属性摘要”后仍可纵向滚动，两条滚动轴互不失效
- [ ] 整个页面没有额外横向泄漏；Header、页签和分页器不跟随表格横滚
- [ ] 调整一列宽度后切到“设置”再返回“索引列表”，列宽和当前实例仍保留

## 3. 搜索与筛选闭环

搜索、状态和类型是“结果筛选”，不是修改勾选项。每次条件变化都应由 Page Host 重新查询，Pane 只显示受控结果。

- [ ] 初始为“全部 + 全部类型”，数量与索引总数一致
- [ ] 输入文件名片段后，仅显示匹配行；总数和“显示起止 / 总数”同步变化
- [ ] 输入 PartNumber、路径片段或中文标签时也能命中对应行
- [ ] 清空搜索后恢复当前状态/类型条件下的完整结果
- [ ] 选择“存在”后没有 `missing` 行
- [ ] 选择“缺失”后没有 `present` 行
- [ ] 分别选择 FCStd、MD、PDF、DXF/DWG、图片，结果类型与按钮一致
- [ ] 搜索、状态、类型可以组合使用，结果为三个条件的交集
- [ ] 从第 2 页修改任一筛选条件后自动回到第 1 页
- [ ] 快速连续输入时最终只显示最后一次输入对应结果，没有旧请求覆盖新结果
- [ ] 切到“设置”再返回时筛选值不丢失
- [ ] 刷新或恢复页面会话后，搜索、筛选、页大小按当前会话规则恢复

## 4. 空状态与加载状态

- [ ] 首次加载或重新查询时显示“加载索引列表…”且不残留旧行
- [ ] 搜索没有命中时显示“无匹配条目，请调整搜索或筛选”
- [ ] 搜索为空但筛选组合没有结果时显示“当前筛选无条目”
- [ ] 工作区尚无索引时显示“尚无索引，点击「工程内搜索」开始扫描”
- [ ] 四种状态都不会显示失真的分页器或 `1–0` 范围
- [ ] 从空状态恢复到有数据状态后表格、滚动条和分页器重新出现

## 5. 十二列、打开动作与分页

- [ ] 列顺序为：#、状态、类型、文件名、零件标识、版本、类型码、型号系列、零件名、标签、相对目录、属性摘要
- [ ] `missing` 行使用缺失视觉状态，且文件名不能打开文件详情
- [ ] `present` FCStd 文件名可打开正确的文件详情，路径没有串行
- [ ] 有完整 PartKey 的“零件标识”可打开正确的零件详情
- [ ] 不完整 PartKey 显示原值但不产生错误导航
- [ ] 每页 20、50、100 三个选项均可切换，切换后回到第 1 页
- [ ] 20 条模式下翻到第 2 页，范围、首行序号和末行序号正确
- [ ] 上一页/下一页边界按钮状态正确，不会越界或重复请求

## 6. 360px 窄宽度

把列表可用宽度压缩到约 360px；可以缩窄窗口，也可以使用仓库中的 Browser fixture `?narrow=1` 场景。

- [ ] 搜索框保持可输入，不超出列表边界
- [ ] 状态、类型筛选会换行且仍可点击，没有按钮被裁掉
- [ ] 数量摘要可读，不覆盖筛选按钮
- [ ] 表格只在自身内部横向滚动，页面外层没有横向滚动条
- [ ] 压缩高度后仍同时具备内部横向和纵向滚动
- [ ] 分页器允许换行但所有动作仍可点击

## 7. 自动门禁与组件边界

以下项目由维护者或 Codex 执行，用于补足人工观察无法证明的边界；通过结果应归档到阶段评测报告。

```bash
pnpm -C web-ui typecheck
pnpm -C web-ui test
pnpm -C web-ui build
pnpm verify:architecture
pnpm verify:wing-dependencies
pnpm docs:check
```

- [ ] Browser 实测正常宽度下 `scrollWidth > clientWidth` 且 `scrollHeight > clientHeight`
- [ ] Browser 实测 360px 下筛选区无横向溢出，表格仍同时可横纵滚动
- [ ] Browser 点击搜索、状态、类型后，行数、总数和范围真实改变
- [ ] Browser 点击文件、PartKey、页码和页大小后，上行 payload 正确
- [ ] `FcstdMapIndexPane` 不导入 API、Shell、Controller、storage 或 session
- [ ] `FcstdMapPage` 继续拥有查询 Controller、session 真源和导航安全复核
- [ ] `v-show` 留在 Page，切换子页签不会销毁 Pane 实例
