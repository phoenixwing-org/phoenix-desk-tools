# 文件详情 · 引用/装配变更缓存刷新 · 归档

> 实现：`web-ui/src/pages/FileDetailPage.vue` · `FileXrefPanel.vue` · `FileAssemblyPanel.vue`  
> 最后更新：2026-06-22

---

## 问题

「引用」Tab 改链接、重建索引、Label 同步后只 `invalidateXrefCache`，「装配结构」Tab 仍读旧 `assemblyCacheByKey`，需手动切 Tab 或刷新才更新。

---

## 改动

| 项 | 说明 |
| --- | --- |
| `notifyXrefMutation` | 同时清除 xref + assembly 缓存，并 bump `xrefMutationSeq` |
| `FileXrefPanel` | 改链接 / 重建索引 / Label 同步后调用 `notifyXrefMutation` |
| `FileAssemblyPanel` | watch `xrefMutationSeq`，在装配 Tab 时 `loadAssemblyTree({ force: true })` |
| `FileRenamePanel` | 改名后同样 `notifyXrefMutation` |

---

## 验收

| 场景 | 预期 |
| --- | --- |
| 引用 Tab「改链接」→ 切装配 Tab | 树与出向表一致 |
| 引用 Tab「重建索引」 | 装配 Tab 已打开时自动重载 |
| 装配 Tab 内「改链接」 | 原有 `@xref-replaced` 仍有效 |

**结论**：引用与装配子 Tab 缓存联动失效，避免 stale 树。
