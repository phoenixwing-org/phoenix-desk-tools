## 近期 Web 更新（2026-06）

| 区域 | 变更摘要 |
| --- | --- |
| **主页 / 配置** | 默认主页简介；配置独立 `config` 页；工具栏/侧栏配置入口 |
| **BOM 列表** | 链接标签列置前、可点进文件详情；类型码列收窄；分组子行缩进收紧；统一展开三角 |
| **文件详情** | 装配结构 Tab；引用/装配 **改链接**；文件名草稿；Tab 按 `repo_rel` / PartKey 去重；改名目标名带入 |
| **属性推荐** | 标准件（S）推荐文件名不含型号系列，推荐时清空 ModelSeries |
| **工作区树** | 展开三角可配置（Pinia + 配置页滑块）；无 Tab 接管时点击 FCStd 回退文件详情 |
| **零件目录** | 标签列置前，打开零件详情（同键复用 Tab） |

实现参考：`HomePage.vue`、`ConfigPage.vue`、`BomExportPage.vue`、`FileDetailPage.vue`、`useAppShell.ts`（`detailTabRoute.ts`）、`stores/uiPrefs.ts`。
