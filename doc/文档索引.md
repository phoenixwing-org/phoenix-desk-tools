## 近期 Web 更新（2026-06）

| 区域 | 变更摘要 |
| --- | --- |
| **主页 / 配置** | 配置为**居中 Modal**；工具栏/侧栏 `goToPage('config')` |
| **BOM 列表** | 链接标签列置前、可点进文件详情 |
| **文件详情** | 装配结构 Tab；引用/装配 **改链接**；改名记录→改名分析 |
| **Code 模块** | Code 索引页；导航模块偏好下工作空间树筛选；UUID 页同值组、工作集扫描、单行策略栏 |
| **壳层 · FileWorkset** | 侧栏工作集 Tab、树/索引归集、UUID `WorksetScopePicker` — 见 [FileWorkset-规划.md](platform/FileWorkset-规划.md) |
| **壳层 · 顶栏** | 页面 Tab 居中 + 当前 Tab 强调动画；标题 `Phoenix 桌面工具 - 工作空间 · 页` |
| **壳层 · 单元测试** | 运行范围列表可**按模块勾选**（默认全选）；`include_modules` API |
| **CAD · 链接修正** | 分析前校验 CAD 索引；索引为空时明确中文提示 |
| **壳层改型（规划）** | Element Plus + Ribbon 分期 — 见 [Web壳层-Ribbon改型-规划.md](platform/Web壳层-Ribbon改型-规划.md) |
| **新手指引** | 主页四步清单、`GET /api/onboarding/status`、driver.js 壳层巡游 |

实现参考：`OnboardingChecklist.vue`、`stores/onboarding.ts`；用户文档见 [user/新手指引.md](user/新手指引.md)。

源码：`phoenix/`；命令行：`scripts/`（详见 `scripts/README.md`）。
