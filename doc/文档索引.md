## 近期 Web 更新（2026-06）

| 区域 | 变更摘要 |
| --- | --- |
| **主页 / 配置** | 配置为**居中 Modal**；工具栏/侧栏 `goToPage('config')` |
| **BOM 列表** | 链接标签列置前、可点进文件详情；类型码列收窄；分组子行缩进收紧；统一展开三角 |
| **文件详情** | 装配结构 Tab；引用/装配 **改链接**；**编辑属性显示文档类型**；改名记录→改名分析 |
| **属性推荐** | 标准件（S）推荐文件名不含型号系列，推荐时清空 ModelSeries |
| **工作区树** | 展开三角可配置（Pinia + 配置页滑块）；无 Tab 接管时点击 FCStd 回退文件详情 |
| **零件目录** | 标签列置前，打开零件详情（同键复用 Tab） |
| **新手指引** | 主页四步清单、`GET /api/onboarding/status`、工作空间门禁、driver.js 壳层巡游 |

实现参考：`OnboardingChecklist.vue`、`stores/onboarding.ts`、`useShellTour.ts`、`useAppShell.ts`；用户文档见 [新手指引.md](新手指引.md)。
