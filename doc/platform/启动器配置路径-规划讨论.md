# 启动器配置路径 — 规划讨论

> 状态：**已实现**（2026-05）  
> 实现：`phoenix/config/launcher_paths.py`、`user_prefs.migrate_launcher_prefs()`

---

## 1. 为什么要换位置

**当前主路径**：见下表（`phoenix/config/launcher_paths.py`）。  
**旧路径**（只读迁移）：`web-ui/.local/launcher.json`、`phoenix/config/workspace.custom.json`。

| 问题 | 说明 |
| --- | --- |
| 绑在源码树里 | 配置落在 `web-ui/.local/`，与 Vue 工程目录混在一起；换克隆目录、删仓库、多份 checkout 会各有一份 launcher |
| 不像「本机软件设置」 | 用户期望最近打开、FreeCAD 路径在系统惯用位置（Windows LocalAppData、macOS Application Support），而不是项目子目录 |
| 与 bridge 不一致 | FreeCAD 收件箱桥接已在 `~/.phoenix/freecad_bridge/`，launcher 却在仓库内，本机 Phoenix 数据分散两处 |

**launcher.json 里存什么（不变）**：

- `recent_workspaces` — 最近工作空间根
- `freecad_dir` — FreeCAD 安装目录
- `window_geometry` — 桌面壳窗口（仅 Tk）
- `shell_layout` — Web / 桌面壳侧栏、右栏宽度等

**仍不放进 launcher 的**：各功能页 STEP 目录、XLink 选项等 → 工作空间 **`.phoenix/phoenix-workspace-prefs.json`**（目标态 SQLite 见 Phoenix 存储讨论）。

## 2. 推荐目标路径

采用 **各平台惯用目录** 下的 **`phoenix-wing/phoenix/`**（与 Gitee 组织 PhoenixWing321 一致；其下 `phoenix` 为本工具配置）。

| 平台 | 推荐目录 | `launcher.json` 完整路径 |
| --- | --- | --- |
| **macOS** | `~/Library/Application Support/phoenix-wing/phoenix/` | `…/phoenix-wing/phoenix/launcher.json` |
| **Windows** | `%LOCALAPPDATA%\phoenix-wing\phoenix\` | `…\phoenix-wing\phoenix\launcher.json` |
| **Linux** | `$XDG_CONFIG_HOME/phoenix-wing/phoenix/` | `~/.config/phoenix-wing/phoenix/launcher.json` |

### macOS 说明

- **`Application Support/phoenix-wing/phoenix/`** 符合 Apple 对 GUI 应用「本机生成数据」的惯例；`phoenix-wing` 与仓库组织一致，避免与其它软件的 `phoenix` 目录冲突。
- 备选 **`~/.phoenix/launcher.json`**：与现有 **`~/.phoenix/freecad_bridge/`** 同父目录，实现最简单；若采用本方案，建议在 macOS 文档里仍写清「与系统 Application Support 等价用途，仅为与 bridge 同目录」。
- **本讨论稿首选 Application Support**；实现阶段若优先「一处找齐 bridge + launcher」，可改为 `~/.phoenix/` 并在本文记录决策。

### Windows 说明

- **`LocalAppData`**（非 `Roaming`）：本机路径、换域账号不同步，适合 FreeCAD 安装路径、最近 CAD 工程列表。
- 与 VS Code、多数 Electron 应用「用户设置在本机」一致。

### Linux 说明

- 配置类 JSON 放 **`~/.config/phoenix/`**（XDG Base Directory）。
- 若日后 bridge 也迁出 home dot 目录，队列数据可放到 **`~/.local/share/phoenix/`**（XDG data）。

## 3. 与 `~/.phoenix/freecad_bridge` 的关系

| 组件 | 当前 | 建议 |
| --- | --- | --- |
| launcher | `web-ui/.local/launcher.json`、旧 `…/phoenix-wing/phoenix/`、单层 `…/phoenix/` | `…/phoenix-wing/phoenix/launcher.json` |
| 收件箱桥 | `~/.phoenix/freecad_bridge/` | **短期不动**；长期可迁到同一 `{platform}/phoenix/` 下子目录 `freecad_bridge/` |

Windows 上 bridge 若在 `%USERPROFILE%\.phoenix\` 而 launcher 在 `%LOCALAPPDATA%\phoenix-wing\phoenix\`，会短暂两处；可接受，或在同一次重构里把 bridge 一并迁到 `LocalAppData\phoenix-wing\phoenix\freecad_bridge\`。

## 4. 迁移策略（实现时）

1. **解析顺序**（建议）  
   `PHOENIX_LAUNCHER_CONFIG`（或 `PHOENIX_LAUNCHER_CONFIG`）→ **新** `…/phoenix-wing/phoenix/launcher.json` → 旧 `…/phoenix-wing/fcdesk/launcher.json` → 单层 `…/fcdesk/launcher.json` → `web-ui/.local/launcher.json` → `workspace.custom.json`

2. **首次启动**  
   若新路径不存在、旧路径有内容：合并写入新路径（逻辑可复用现有 `migrate_launcher_prefs_to_web` / `_merge_launcher_prefs`）。

3. **旧文件**  
   迁移成功后**不自动删除** `web-ui/.local/launcher.json`，避免误删；配置页或日志提示「已迁到 …，可手动删除旧文件」。

4. **示例文件**  
   保留 `web-ui/config/launcher.json.example` 作字段说明；注释中改为「实际路径见 doc/platform/启动器配置路径-规划讨论.md」。

5. **API**  
   `launcher_config_path` 返回**真实读写路径**，配置页 footer 自动显示新位置。
