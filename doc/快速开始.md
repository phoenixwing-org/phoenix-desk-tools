# 快速开始（约 5 分钟）

> 详细说明：[新手指引.md](新手指引.md) · 壳层说明：[Web壳层-使用说明.md](Web壳层-使用说明.md)

## 操作清单

| 步 | 必做 | 操作 | 入口 |
| --- | --- | --- | --- |
| 1 | 是 | 填 **工作空间根** → **保存偏好** | 侧栏 **配置** |
| 2 | 推荐 | 填 **FreeCAD 目录** → 保存 | 同上 |
| 3 | 是 | **工程内搜索**（扫 CAD 索引） | 侧栏 **CAD 索引** |
| 4 | 是 | 右侧树点击 **`.FCStd`** 打开文件详情 | 侧栏 `»` 展开树 |

## 启动 Web

```bash
pip install -e ".[web]"
pnpm install
python -m fcdesk.web --build -w /path/to/CAD/workspace
# 浏览器 http://127.0.0.1:5173
```

开发热更新：`python -m fcdesk.web --dev -w /path/to/workspace`（见 [web-ui/README.md](../web-ui/README.md)）。

## 主页进度

打开 **主页** → **新手指南**：步骤旁 ✓ 表示已完成；全部必做步完成后显示 **已可开工**。

可选：**开始界面巡游**（约 1 分钟熟悉界面）。

## 注意

- **STEP 批量**：必须先完成步骤 2（FreeCAD 目录）。
- 未保存工作空间时，侧栏功能项不可用（仅主页、配置可进）。
