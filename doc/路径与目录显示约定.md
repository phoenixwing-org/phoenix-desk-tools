# 路径与目录显示约定

本文说明 **fcdesk** 桌面壳里：**目录如何选择、怎样写入配置文件、如何在界面上显示**。实现集中在 `fcdesk/config/user_prefs.py`、各功能页、`fcdesk/shell/native_dialog.py`（选目录对话框）。

---

## 1. 两套配置，不要混用

| 层级 | 文件位置 | 作用 |
| --- | --- | --- |
| **启动器** | `fcdesk/config/workspace.custom.json` | 最近工作空间列表、`freecad_dir`、主窗口 `window_geometry` 等。**与某一个仓库根无关**的全局项 |
| **工作空间** | `<工作空间根>/.phoenix-freecad-desktop.json` | XLink、STEP 批量、`fcstd_map`、SolidWorks STEP、零件去重等页的偏好 |

与工作空间相关的路径字段存放在 **第二点** 的文件里（按小节名如 `step_batch`、`fc_linkfix` 等）。

---

## 2. 配置页 vs 其余功能页

### 配置页（导航「home」/`配置`）

- **工作空间根**、**FreeCAD 目录**在输入框里**始终显示规范化后的绝对路径**（`expanduser` + `resolve`）。
- **不代表**「相对当前工作空间的子路径」，因此**不加** `./` 前缀逻辑。
- 辅助函数：**`format_absolute_config_path`**（`user_prefs.py`）。

### 其余功能页（XLink、STEP 批量、FCStd 索引、SolidWorks STEP、零件去重等）

路径语义是：**相对于当前工具条所选「工作空间根」**，除非解析后为**落在工作空间树外**的绝对路径。

- **若在树内**：JSON 里存 **相对 posix**（canonical，无多余 `./`、`../` 段）。
- **若在树外**：JSON 里存 **绝对路径字符串**。
- 统一写盘：**`store_path_under_repo`**（内部对树内路径用 `Path.relative_to(工作空间根).as_posix()` 再做规范化）。
- 从 JSON 读并解析成真实路径：**`resolve_pref_path`**（绝对则直接解析；否则 `工作空间根 / 片段`）。

---

## 3. 界面展示规则（与 JSON 可否一致）

### 3.1 树内路径：相对 + 前缀 `./`

为提示「相对于工作空间根」，**仅界面**上对树内路径使用：

- **`format_resolved_under_workspace`**：已由绝对路径 + 工作空间根算出展示串；树内结果为 **`./子路径/…`**（经 canonical），工作空间根本身为 **`"."`**。
- **`format_stored_path_for_display`**：读配置字段 → `resolve_pref_path` → 再 **`format_resolved_under_workspace`**，因此与上图一致。
- **`format_relative_workspace_for_ui`**：单独把 canonical 片段（如工程子路径）变成 **`./…`**（`../` 开头的不强行加 `./`）。
- STEP 页的 **「工程路径」**：仍是相对工作空间的**片段**，展示时同样走 **`./`** 前缀；存盘前用 **`normalize_workspace_subpath`** 去掉多余 `./`、`../` 段（仅保留片断本身）。

### 3.2 树外路径

展示为 **规范绝对路径**（与用户机器上的解析结果一致），**不加** `./`。

### 3.3 「留空表示工作空间根」

部分输入框占位说明为「留空 = 扫描工作空间根」等。内部 canonical 的树内 **`"."`** 在经过 **`shorten_workspace_relative_display`** 后显示为 **空字符串**，便于和占位一致。**STEP 批量**等必填路径若就是根，仍可能出现 **`"."`**（因不能留空误判未填）。

---

## 4. 输入解析（把框里字符串变回 Path）

常用入口：

| 场景 | 函数 | 行为摘要 |
| --- | --- | --- |
| 大部分「相对工作空间的目录」框 | **`resolve_workspace_path_entry`** | 空白或 **`"."`** → 工作空间根；否则相对根拼接并 `resolve` |
| STEP「工程路径」等与根拼接的**短片断** | **`normalize_workspace_subpath`** | 规范片断，去掉前导 `./`，供 `repo_root / 片断` |

绝对路径若以盘符 **`/`**（Unix）或 **`C:\`**（Windows）等形式出现，由各页现有的 **`Path(...).is_absolute()`** 分支处理（与 **`resolve_workspace_path_entry`** / `store_path_under_repo` 等配合）。

---

## 5. 选目录对话框（浏览…）

统一入口：**`pick_workspace_directory`**（`fcdesk/shell/native_dialog.py`）。

- 初始目录由 **`resolve_directory_dialog_initialdir`** 决定：  
  若 **`path_hint`** 能解析且存在 → 指向该目录；否则 → **当前工作空间根**；仅在根无效等极端情况退回用户文档目录等。
- 标题里会带出当前工作空间根（节选），便于对齐上下文。

选好目录后，各页一般用 **`format_resolved_under_workspace`**（或再配合 **`shorten_workspace_relative_display`**）写回输入框，以保持与上文展示规则一致。

---

## 6. 后缀与文件名（与本节「目录约定」并行）

零件去重等对扩展名的匹配：**大小写无关**（`Path.suffix` + `casefold`），与工作空间路径规则无关，仅避免 macOS 区分大小写卷上漏扫 `.FCStd` 等。

---

## 7. 维护时改哪里

- **全局长度的展示或存盘语义**：优先考虑 **`user_prefs.py`** 中上述函数，避免各页复制粘贴。
- **某一页特例**：在该页 `_persist` / `on_show` / 浏览回调中查阅是否已复用 **`format_stored_path_for_display`**、`format_resolved_under_workspace`、`resolve_workspace_path_entry`。
- **配置页的绝对路径**：只用 **`format_absolute_config_path`**，不要混用 `./` 相对展示逻辑。
