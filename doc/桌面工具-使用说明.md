# FreeCAD 辅助工具 — 使用说明

**推荐**：用 **Web 壳** 完成全部功能（CAD 索引、BOM、文件详情、XLink 等）。桌面 `python -m fcdesk` 仅作**启动器**（选工作空间、打开浏览器）。

| 形态 | 说明 | 文档 |
| --- | --- | --- |
| **Web 壳** | `python -m fcdesk.web`，浏览器操作 | [新手指引.md](新手指引.md)、[Web壳层-使用说明.md](Web壳层-使用说明.md)、[web-ui/README.md](../web-ui/README.md) |
| **桌面壳（遗留）** | CustomTkinter 全功能页（逐步迁移中） | 下文 § 布局、§ 页面 |

安装见 [桌面工具-安装说明.md](桌面工具-安装说明.md)。

## Web 快速入口

```bash
source .venv-desktop/bin/activate
python -m fcdesk.web --build -w /path/to/CAD/workspace
```

首次使用请读 [快速开始.md](快速开始.md)（约 5 分钟）。

---

## 桌面壳启动（遗留）

```bash
source .venv-desktop/bin/activate
python -m fcdesk
```

全屏时窗口可能在另一个 Space：Mission Control / Cmd+Tab。

## 配置

### `fcdesk/config/app_config.json`

- **`app`**：`title`、`geometry`、`appearance_mode`、`color_theme`
- **`toolbar.items`**：`action` 须在 `fcdesk/shell/app.py` 的 `_toolbar_actions()` 实现；分隔线：`{ "separator": true }`
- **`navigation[].page`**：须在 `_register_pages` 中注册

### 用户偏好（与 app_config 分离）

| 文件 | 位置 | 用途 |
| --- | --- | --- |
| `launcher.json` | **本机** `…/phoenix-wing/fcdesk/` | 最近工作空间、`freecad_dir`、Web 壳布局 |
| `workspace.custom.json` | `fcdesk/config/`（旧，兼容读取） | 桌面壳遗留；启动时合并到本机 launcher |
| `.phoenix/phoenix-freecad-desktop.json` | **各工作空间** `.phoenix/` 目录 | `fc_linkfix`、`fcstd_map`、`step_batch` 等（与 `phoenix-workspace.sqlite` 同目录） |
| `.phoenix-freecad-desktop.json` | 工作空间根（**遗留**） | 启动时自动迁入 `.phoenix/` |

详见 [fcdesk/config/README-launcher.md](../fcdesk/config/README-launcher.md)。

明细见 [路径与目录显示约定.md](路径与目录显示约定.md)。旧版「单文件内嵌全部配置」会自动迁到工作空间根点文件。

> **规划方向（未实现）**：默认改为 **`.phoenix/phoenix.sqlite`** 存工作空间偏好与审计；**不**自动生成根目录 dotfile；需要时用 **「导出 JSON」** 生成兼容快照。见 [Phoenix工作空间存储-规划讨论.md](Phoenix工作空间存储-规划讨论.md)。

## 页面（与导航对应）

| 页面 | 说明 |
| --- | --- |
| 配置 | 工作空间、FreeCAD 目录（Web 壳见导航 **配置** `config`） |
| CAD 索引 | 从**工作空间根**扫描写入 **`.phoenix/phoenix-workspace.sqlite`**（无子目录扫描根）；Web 可导出 JSON、**删除缺失**；桌面为「创建索引」+ 表格 |
| 链接路径修正 | 依赖 CAD 索引 SQLite；Web：**先分析**（表格列失效/可修正 XLink）再**执行修正**；底层 `fix_fcstd_xlink_paths.py` |
| STEP 批量 | FreeCADCmd 或收件箱桥接；见 [STEP批量转FCStd.md](STEP批量转FCStd.md)、[FreeCAD-fcdesk桥接.md](FreeCAD-fcdesk桥接.md) |
| SW→STEP | Windows SolidWorks COM；见 [SolidWorks批量STEP导出.md](SolidWorks批量STEP导出.md) |
| BOM 列表 | 装配 BOM / 全部引用；见 [BOM列表页设计.md](BOM列表页设计.md) |
| 文件详情 / 属性回写 | 文件详情壳（概览 / 属性 / 引用 / 改名）；图纸 `.Drawing.FCStd` BOM **只读**，见 [图纸档-BOM属性规划.md](图纸档-BOM属性规划.md) |
| 编号查重 | 文件名 / 编号+版本分组 |
