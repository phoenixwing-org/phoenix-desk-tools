# FreeCAD 辅助桌面壳 — 使用说明

基于 **CustomTkinter**：左侧导航、右侧页面；可选 **`app_config.json` → `toolbar.items`** 可增加顶部按钮。常用路径与工作空间设置在 **左侧「配置」** 页。**窗口标题** 为 `app.title · 【当前工作空间根】`。部分页面通过子进程调用 `scripts/` 下的命令行工具。

安装步骤见 [桌面工具-安装说明.md](桌面工具-安装说明.md)。

## 启动

```bash
source .venv-desktop/bin/activate   # 仓库根目录
python -m fcdesk
```

全屏时独立窗口可能在另一空间：Mission Control / Cmd+Tab。

## 配置 `fcdesk/config/app_config.json`

### `app`

| 字段 | 说明 |
| --- | --- |
| `title` | 应用名称；启动后窗口标题为 **`{title} - 【工作空间根】`** |
| `geometry` | 初始窗口大小 |
| `appearance_mode` | `system` / `light` / `dark` |
| `color_theme` | CustomTkinter 主题色 |

### `toolbar.items`

默认 **空数组**（不显示工具条）。若添加按钮，`action` 须在 `fcdesk/shell/app.py` 的 `_toolbar_actions()` 中实现。分隔线：`{ "separator": true }`。

### `navigation`

`page` ID 须在 `_register_pages` 中注册；新增页面时请同步修改 JSON。

## 用户偏好：`workspace.custom.json`

与 **静态界面配置** `app_config.json` 区分开：记录**你这边的路径与选项**，程序自动读写；可按功能分区；模板：`fcdesk/config/workspace.custom.json.example`。

| JSON 节点 | 内容 |
| --- | --- |
| `toolbar` | 工作空间根、`FreeCAD 目录`（由 **配置** 页的「浏览…」与「保存偏好」写入 |
| `fc_linkfix` | `cad_search_root`：不设或 `null` 时与工作空间一致；另有批量目录、`dry_run`、`all_in_dir`。**链接修正**读 **`{CAD搜索根}/fc_linkfix_fcstd_map.json`**；JSON 内 `repo_rel_path` **相对 CAD 搜索根**（映射文件目录），形如 `./Sample…/零件.FCStd` |
| `fcstd_map` | 索引扫描根（链接修正导出时 **`--relative-to`** 宜用与 **`--root`** 相同的 CAD 目录） |

文件路径：`fcdesk/config/workspace.custom.json`（已在仓库 `.gitignore` 忽略，可自行备份）。

## 已实现功能（概述）

| 页面 | 说明 |
| --- | --- |
| 配置 | 工作空间根、FreeCAD 目录的可视化编辑与 **`workspace.custom.json` 保存**；重载 `app_config`、关于 |
| 链接路径修正 | 「建立/更新映射」→ **`{CAD搜索根}/fc_linkfix_fcstd_map.json`**；`cad_search_root` 未设时用工作空间。`resolve` 时用 **`--map-anchor` = 该 CAD 搜索根（与 `--relative-to` 一致）** |
| FCStd 索引 | `fcstd_map.py`；导出完整库索引时可另设扫描根 |
