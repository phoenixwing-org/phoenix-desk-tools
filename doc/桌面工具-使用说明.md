# FreeCAD 辅助桌面壳 — 使用说明

基于 **CustomTkinter**：左侧导航、中间页面栈；右侧工作空间树。**`app_config.json`** 可调标题、导航、工具条。安装见 [桌面工具-安装说明.md](桌面工具-安装说明.md)。

## 启动

```bash
source .venv-desktop/bin/activate
python -m fcdesk
```

全屏时窗口可能在另一个 Space：Mission Control / Cmd+Tab。

## 布局示意

```
┌─────────────────────────────────────────────────────────────┐
│ （可选 toolbar.items）                                       │
├───┬───────────────────────────────────────────┬───────────┤
│导航│               页面内容                      │工作空间树│
├───┴───────────────────────────────────────────┴───────────┤
│ 状态栏                                                      │
└─────────────────────────────────────────────────────────────┘
```

## 配置

### `fcdesk/config/app_config.json`

- **`app`**：`title`、`geometry`、`appearance_mode`、`color_theme`
- **`toolbar.items`**：`action` 须在 `fcdesk/shell/app.py` 的 `_toolbar_actions()` 实现；分隔线：`{ "separator": true }`
- **`navigation[].page`**：须在 `_register_pages` 中注册

### 用户偏好（与 app_config 分离）

| 文件 | 位置 | 用途 |
| --- | --- | --- |
| `workspace.custom.json` | `fcdesk/config/`（本机 `.gitignore`） | 最近工作空间、`freecad_dir`、窗口几何等 |
| `.phoenix-freecad-desktop.json` | **各工作空间根** | `fc_linkfix`、`fcstd_map`、`step_batch`、`sw_step_export`、`part_dedup` 等 |

明细见 [路径与目录显示约定.md](路径与目录显示约定.md)。旧版「单文件内嵌全部配置」会自动迁到工作空间根点文件。

## 页面（与导航对应）

| 页面 | 说明 |
| --- | --- |
| 配置 | 工作空间、FreeCAD 目录、`app_config` 重载 |
| FCStd 索引 | `scripts/fcstd_map.py`，写出根目录 **`fcstd_map.json`** |
| 链接路径修正 | **`fix_fcstd_xlink_paths`**；`--map-anchor` = 工作空间根 |
| STEP 批量 | FreeCADCmd 或收件箱桥接；见 [STEP批量转FCStd.md](STEP批量转FCStd.md)、[FreeCAD-fcdesk桥接.md](FreeCAD-fcdesk桥接.md) |
| SW→STEP | Windows SolidWorks COM；见 [SolidWorks批量STEP导出.md](SolidWorks批量STEP导出.md) |
| BOM 提取 | 占位，未接逻辑 |
| 属性回写 | ZIP 侧车 **`FcdeskBomAttrs.xml`**；[Fcdesk嵌入式BOM属性约定.md](Fcdesk嵌入式BOM属性约定.md) |
| 编号查重 | 文件名 / 编号+版本分组 |
