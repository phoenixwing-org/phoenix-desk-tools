# FreeCAD 辅助桌面壳 — 使用说明

基于 **CustomTkinter**：左侧导航、右侧页面；可选 **`app_config.json` → `toolbar.items`** 可增加顶部按钮。常用路径与工作空间设置在 **左侧「配置」** 页。**窗口标题** 为 `app.title · 【当前工作空间根】`。部分页面通过子进程调用 `scripts/` 下的命令行工具。

安装步骤见 [桌面工具-安装说明.md](桌面工具-安装说明.md)。

## 启动

```bash
source .venv-desktop/bin/activate   # 仓库根目录
python -m fcdesk
```

全屏时独立窗口可能在另一空间：Mission Control / Cmd+Tab。

## 仓库布局（与源码对应）

```
phoenix-freecad-desktop/
  fcdesk/
    config/app_config.json    # 工具条 + 左侧导航（JSON）
    shell/                    # 主窗口、工具条、导航、页面栈
    pages/                    # 各功能面板
  scripts/                    # fcstd_map、fix_fcstd_xlink_paths 等
  doc/                        # 本文档目录
```

## 配置 `fcdesk/config/app_config.json`

### `app`

| 字段 | 说明 |
| --- | --- |
| `title` | 应用名称；启动后窗口标题为 **`{title} - 【工作空间根】`** |
| `geometry` | 初始窗口大小 |
| `appearance_mode` | `system` / `light` / `dark` |
| `color_theme` | CustomTkinter 主题色 |

### `toolbar.items`

默认 **空数组**（不显示工具条）。若添加按钮，`action` 须在 `fcdesk/shell/app.py` 的 `_toolbar_actions()` 中实现。分隔线：`{ "separator": true }`。

### `navigation`

`page` ID 须在 `_register_pages` 中注册；新增页面时请同步修改 JSON。

## 用户偏好（两层）

与 **静态界面配置** `app_config.json` 区分开，路径与选项由程序自动读写。

| 文件 | 位置 | 内容 |
| --- | --- | --- |
| `workspace.custom.json` | `fcdesk/config/`（本机，`.gitignore`） | **最近打开的工作空间**（最多 10 个）、本机 **FreeCAD 安装目录**；模板：`workspace.custom.json.example` |
| `.phoenix-freecad-desktop.json` | **各工作空间根目录** | 该仓库下的 `fc_linkfix`、`fcstd_map`、`step_batch`、`sw_step_export` 等；模板：`workspace.dotfile.example` |

| 点文件节点 | 内容 |
| --- | --- |
| `fc_linkfix` | `cad_search_root`：不设或 `null` 时与工作空间一致；另有批量目录、`dry_run`、`all_in_dir` |
| `fcstd_map` | 索引扫描根 |
| `step_batch` / `sw_step_export` | 各功能页「保存偏好」写入 |

首次启动若仍存在旧版「单文件内嵌全部配置」，会自动迁到当前工作空间根下的 `.phoenix-freecad-desktop.json`。

## 已实现功能（概述）

| 页面 | 说明 |
| --- | --- |
| 配置 | 工作空间根、最近列表、FreeCAD 目录；重载 `app_config`、关于 |
| 链接路径修正 | 「建立/更新映射」→ **`{CAD搜索根}/fc_linkfix_fcstd_map.json`**；`cad_search_root` 未设时用工作空间。`resolve` 时用 **`--map-anchor` = 该 CAD 搜索根（与 `--relative-to` 一致）** |
| FCStd 索引 | `fcstd_map.py`；导出完整库索引时可另设扫描根 |
