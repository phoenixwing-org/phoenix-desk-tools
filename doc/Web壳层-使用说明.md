# Web 壳层 — 使用说明

浏览器中的 **FreeCAD 管理工具** 界面（Vue3 + Python API）。首次使用请先读 [新手指引.md](新手指引.md) 或 [快速开始.md](快速开始.md)。

启动方式见 [web-ui/README.md](../web-ui/README.md)。

---

## 1. 布局

```
┌──────────────────────────────────────────────────────────────────┐
│ 工具栏：工作空间芯片 · 最近 · 配置 · 状态                        │
├───┬──────────────────────────────────────────────┬───────────────┤
│导航│  Tab 栏（多页签）                              │ 工作空间树    │
│   │  ┌────────────────────────────────────────┐  │ （可筛选）    │
│   │  │ 当前功能页 / 文件详情 / …               │  │               │
│   │  └────────────────────────────────────────┘  ├───────────────┤
│   │                                              │ 运行日志      │
├───┴──────────────────────────────────────────────┴───────────────┤
│ 状态栏                                                          │
└──────────────────────────────────────────────────────────────────┘
```

| 区域 | 作用 |
| --- | --- |
| **左侧导航** | 主页、各功能入口；底部 **? 新手指引**、**配置**；`▶`/`◀` 切换窄栏 / 宽栏 |
| **页内 ?** | 多数功能页标题旁：**?** 打开本页要点（弹层）；有步骤的页可点 **本页导引**（driver.js 高亮 2～4 处，仅当前页） |
| **帮助策略** | 全局：侧栏 **? 新手指引** + 主页清单 + **界面巡游**（全壳层）；上下文：**?** 短说明，不做每页完整文档索引（与 Notion/GitHub 等「上下文帮助」类似） |
| **Tab 栏** | 已打开页面；可关闭单个 Tab；关闭全部后回到 **主页** |
| **主内容区** | 当前 Tab 对应页面（KeepAlive 保留状态） |
| **工作空间树** | 浏览当前工作空间下 FCStd 等；点击文件打开详情（见 §4） |
| **运行日志** | 扫描、批量任务等输出；可拖拽高度；配置页可调展开图标大小 |

侧栏 `»` / `«`：展开或收起右侧树+日志列。

## 2. 主页与配置

| 页面 | 导航 id | 说明 |
| --- | --- | --- |
| **主页** | `home` | 简介、**新手指南**（四步清单 + 界面巡游）、功能入口卡片 |
| **配置** | `config` | 工作空间根、FreeCAD 目录、最近打开、Web 服务、界面偏好 |

工作空间须在配置中 **保存偏好** 后，才会记入 launcher 最近列表并解锁其它功能（见 [新手指引.md](新手指引.md) § 门禁）。

---

## 3. Tab 与工作台

- 单页功能（如 CAD 索引、BOM 列表）默认 **1 个 Tab**；再次点击导航会激活已有 Tab，不重复打开。
- **文件详情**、**零件详情** 等支持 **多 Tab**（上限见 `app_config.json` → `workbench.pages`）。
- 同一文件路径或同一 PartKey **复用**已有 Tab，不堆叠重复页签。
- 刷新浏览器后，当前工作空间的 Tab 列表与部分页面状态可从服务端会话恢复（`workbench_session`）。

讨论稿：[Web壳层-Tab与状态持久化-规划讨论.md](Web壳层-Tab与状态持久化-规划讨论.md)。

---

## 4. 工作空间树与文件详情

1. 在配置中保存有效 **工作空间根**。
2. 右侧树加载目录；可勾选 FCStd / SW 筛选。
3. 点击 `.FCStd`：
   - 若当前 Tab 注册了树选择处理（如 BOM 列表选装配），由该页接管；
   - 否则 **默认打开文件详情**（属性 / 引用 / 改名等子 Tab）。

树上方搜索框可按路径片段过滤显示。

## 5. 新手指南与门禁（摘要）

| 规则 | 行为 |
| --- | --- |
| 未保存工作空间 | 仅 **主页**、**配置** 可进；侧栏其它项灰色 |
| 未填 FreeCAD | 多数功能仍可用；**STEP 批量** 的预览/转换不可用 |
| 未做 CAD 索引 | **BOM 列表** 顶栏提示先去 CAD 索引扫描 |
| 界面巡游 | 工作空间就绪后，主页或配置中启动（driver.js，约 6 步） |

清单完成状态：`GET /api/onboarding/status` + 浏览器 `localStorage`（详见 [新手指引-实现备忘.md](新手指引-实现备忘.md)）。

## 7. 路径显示

配置页路径为 **绝对路径**；各功能页内多为相对工作空间根的 `./…` 展示。规则见 [路径与目录显示约定.md](路径与目录显示约定.md)。

## 8. 与桌面启动器的关系

`python -m phoenix` 桌面窗口仅用于选工作空间、打开浏览器；**功能均在 Web 壳** 完成，与本节描述一致。
