## 1. 背景

cxx-code-style 下，类内 **函数** 与各 `public:` / `private:` / `protected:` 段已有较完整的重排规则（特殊成员优先、其余字母序、`.cpp` 分隔符等）。

**成员变量（data member）** 字母序是独立能力：涉及 `.h` 声明顺序、Doxygen 编号注释、以及 `.h` 与 `.cpp` 实现块之间的 **序号一致**。规则不止一条，需成组实现后再开放 Web 勾选。

| 能力 | 状态 |

## 3. 目标规则（待实现）

### 3.1 `.h` 成员变量字母序

- 作用范围：各访问段内 **`kind == member`** 的声明（不含 nested enum/struct、不含纯函数段）。
- 排序键：成员名 **不区分大小写** 字母序；同名/宏展开冲突时保持 stable 相对顺序。
- **槽位**：成员变量在段内相对「嵌套类型 / 分组」的位置策略需定稿（现实现：函数排序后，成员仍在原索引槽位内字母序）。

### 3.2 Doxygen 编号重排

部分工程用块注释标记序号，例如：

```cpp
/** 1. 默认构造 */
ClassName();
/** 2. 带参构造 */
ClassName(int x);
/** 3. 析构 */
~ClassName();
```

**规则草案**：

1. 段内发生 **任何顺序变更**（函数或成员）后，该段内所有 **`/** N. … */` 形式** 的编号按 **新顺序从 1 连续重编**。
2. 仅当段内 **≥2 个** 带编号项时才视为「编号序列」；单条编号可视为普通 `@brief`，不参与序列逻辑（与现 `_section_has_numbered_doxygen_sequence` 阈值一致）。
3. 非编号 Doxygen（`@brief`、`@param`、无数字前缀的 `/** … */`）**随声明块移动**，不单独改号。
4. 若段内因 nested / `@name` 组等 **整段跳过排序**，则 **不改编号**（与现 warning 行为一致）。

### 3.3 `.h` 与 `.cpp` 序号一致

当 `.h` 与 `.cpp` 均使用相同编号约定时：

| 场景 | 要求 |
| --- | --- |
| 特殊成员（构造/析构/`operator=`） | `.h` 重排并重编序号后，`.cpp` 中对应实现块 **同序号**；顺序仍遵循：默认构造 → 其它构造 → 析构 → 拷贝/移动 → `operator=` |
| 普通成员函数 | `.h` 声明顺序与 `.cpp` 内 `ClassName::func` 块顺序 **一致**；若使用 `/** N. */` 注释，N 在两侧 **同步** |
| Leading 注释 | `.cpp` 已有「注释随函数移动」；扩展为 **编号注释随块移动并重编** |
| 仅 `.h` 有编号、`.cpp` 无编号 | 只改 `.h`；`.cpp` 仅按函数名规则排序，不强行插入编号 |
| 仅 `.cpp` 有编号 | 预检 warning；是否支持仅 `.cpp` 重编待定 |

### 3.4 冲突与跳过

以下情况 **不自动排序** 或 **只报告 warning**（与现逻辑对齐并扩展）：

- 段内存在 **nested** `class` / `struct` / `enum` / `using`
- Doxygen **`///@{` / `///@}`** 分组（规范要求删除分组后重跑）
- 编号序列 **不连续** 或 **重复序号**（待定义：自动修复 vs 中止）
- 宏生成的成员 / `#if` 条件编译块（待定义：跳过该段 vs 仅排序 `#else` 外部分）

### 3.5 预检与写盘

- **预检**必须输出：将改动的文件、段标签、旧序→新序摘要、编号变更 diff 摘要。
- 编号重编属于 **破坏性变更**：默认预检通过后才允许写盘；verbose 日志列出每个 `/** N.` 的旧 N → 新 N。
