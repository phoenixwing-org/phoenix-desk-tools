# FreeCAD 辅助桌面壳 — 安装说明

外壳基于 **CustomTkinter**，需要 **自带 tkinter** 的 Python 3.10+，并在仓库虚拟环境中安装依赖。

源码仓库：<https://gitee.com/PhoenixWing321/phoenix-freecad-desktop>

## 一、安装 Python（官网安装包，以 macOS 为例）

1. 打开 <https://www.python.org/downloads/macos/> ，下载适合的 **macOS 64-bit universal2 installer**。
2. 安装时勾选 **Install certificate**、**Update Shell Profile**。
3. 新开终端验证：

```bash
python3 --version
python3 -c "import tkinter; print('tkinter OK')"
```

## 二、仓库虚拟环境与依赖

在仓库根目录执行：

```bash
git clone https://gitee.com/PhoenixWing321/phoenix-freecad-desktop.git
cd phoenix-freecad-desktop
python3 -m venv .venv-desktop
source .venv-desktop/bin/activate    # Windows: .venv-desktop\Scripts\activate
pip install -U pip
pip install -r requirements-desktop.txt
```

### macOS 一键脚本

```bash
bash scripts/setup_desktop_venv.sh
```

会使用带 tkinter 的 Python 创建 `.venv-desktop` 并安装依赖。

## 三、启动

```bash
source .venv-desktop/bin/activate
python -m fcdesk
```

若已通过 `pip install -e .` 安装本项目，也可以使用命令 `phoenix-fcdesktop`。

程序功能与配置见 [桌面工具-使用说明.md](桌面工具-使用说明.md)。
