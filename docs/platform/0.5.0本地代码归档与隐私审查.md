## 历史和发布限制

移出当前 Git 树不等于清除历史。本地记录的 `origin/develop` 已有本机产物及两份历史工程 XML，当前未推送范围的 `b5e8a72` 也触及临时目录；仅整理这 13 个本地提交不能清除基线历史。当前归档是本地开发快照，不能直接公开全部 Git 历史。正式发布前须确定整理后的交付/历史范围，再审查实际发布包；本轮不自动重写共享或已发布历史。

原 GUI launcher 凭据事件的撤销/轮换尚待责任方确认，继续列为发布阻断项，不复述旧值。

Registry Server 基线检测为 308 项通过、168 项失败，失败由锁定包缺少新 CAD 接口引发；未执行后续 Web 阶段。消费者 manifest/lock 继续锁定已发布精确版本，未改成 link/file/workspace 或 override。源码改版不等于 Registry 已具备候选接口。
