## CAD 协调与保留边界

已与原 CAD 开发任务只读核对：未发现 `3f00a028` 后遗漏的已提交 CAD 修复。本轮 Server CAD 实现与该来源一致；保留 develop 新的 Tauri 启动契约测试。

- 退役重复全量扫描器、`fcstd_map`、`bom_export` 及其页面专属实现；不会删除用户数据库或 CAD 文件。
- 保留文件详情、属性写回、改名、XLink/Label 修复、PartKey、STEP/SolidWorks adapter。
- CAD 0.6.3 仍需要动态属性元数据兼容层，不能因根包升级而删除。
- 启动入口继续为 `pnpm dev`（Registry）、`pnpm wing`（并列源码）、`tauri:dev` / `tauri:wing`。
- 旧 GUI launcher 的凭据轮换属于外部待确认事项，继续保留于 [TODO](../TODO.md)，本轮不宣称已解决。

详细责任见 [CAD 数据与 API 真源](../cad/CAD数据与API真源.md) 和 [CAD 减法与保留边界](../cad/Desk-CAD减法与保留边界.md)。
