# FreeCAD MCP 安装与连接

状态：current（M0 管理能力；worker 开发候选，非已接通的批处理执行器）

适用范围：Desk 0.5.x 本地源码；最后核对：2026-11-06。

## 入口与真实状态

设置 → FreeCAD →「MCP 安装与连接」只显示简短状态与「管理…」。设置 Header、Primary 和 System Ribbon → FreeCAD → MCP 管理打开同一个紧凑窗口，不新增页面或另一套任务队列。不需要 AI、聊天账户或模型调用。

打开窗口只读取状态，不安装、下载、启动程序或修复配置。界面分别展示可执行文件、所选 Mod 目录、插件文件、正式 MCP 连接和批处理能力。磁盘插件存在不代表运行中已加载，JSON 桥接响应也不代表 MCP 就绪。

默认模式为工具专用批处理实例。Tools 已提供类型化 worker 生命周期，可按完整白名单构建自包含的本地固定资源；Desk 已新增 worker 客户端、自有会话、严格 PNG 校验及外部缓存发布实现，并有定向测试覆盖。设置窗口现已接入显式启动、停止与状态观察，但默认不开放；须由宿主另开候选测试门禁。现有批量任务队列的版本化接线仍未完成，常驻批处理继续明确阻止，不使用脚本或默认端口绕过。已验图像范围包括保存 GUI 状态及无 GUI、显式可见性的独立 `Part::Feature` 盒体与圆柱样件；不能由 PNG 格式正确外推任意文件的图像正确。

普通完整模式 25 项、聊天模式 19 项与独立 worker 模式 4 项工具分别注册；worker 的状态、渲染、查询和取消接口不向普通用户实例开放。用户显式选择已有实例后，只允许检查保存的 `127.0.0.1` 端口；不会发现、猜测、接管或关闭其他实例。

## 受控安装资源

未配置可信本地资源时显示缺失，安装与连接探测不会静默回退并列开发目录、现有 `dist` 或网络包。宿主必须同时提供经过审查的本地清单与固定摘要：

- `PHOENIX_FREECAD_MCP_RESOURCE_MANIFEST`：本地发行清单的绝对路径。
- `PHOENIX_FREECAD_MCP_RESOURCE_SHA256`：清单文件的 SHA-256。

这些是宿主部署参数，不是 HTTP 输入。清单字段为 `schema_version: 1`、`plugin_version`、`addon_dir`、`installer_entry`、可选 `mcp_entry` 和 `files`（相对路径 → SHA-256）。当前只验收 Phoenix 插件与 MCP Node 端 `0.3.2`；其他版本不得自动当作兼容。插件材料须包含 `InitGui.py`、版本一致的 `package.xml`、`LICENSE`、`NOTICE`、`README.md`。安装器为已审查的独立 `install-addon.mjs`，不得带外部导入。

资源按完整白名单核验，不跟随符号链接或硬链接，只将白名单冻结到私有临时目录；不复制整个源码库。入口与所有依赖必须包含在发行清单中。文件数、层级、单文件与累计字节有上限；缺少许可、清单不全或摘要变化均拒绝。冻结资源须覆盖自有进程整个存活期，仅在对应 ChildProcess 实际 `close` 后释放；超时、kill 返回成功、`error` 或 `exit` 都不能代替关闭证明。一直未关闭就保持原资源及启动屏障，不切换命名空间绕过未知状态。

界面显示「本地固定资源」；摘要核验通过不代表正式发布。临时联调资源不作为默认配置或持久部署位置，不把其绝对路径、固定摘要或私有验收回执写入仓库。接入候选只影响明确启动的测试进程，不修改当前正常服务的资源配置。

## 独立 worker 控制候选

仅在已验 macOS raw GUI 路径、完整固定 worker 资源、工具专用模式以及宿主 `PHOENIX_FREECAD_MCP_OWNED_WORKER_TEST=1` 同时成立时，窗口才允许「启动独立worker（连接测试）」。不要求向用户 Mod 安装插件；冻结资源使用本次自有私有配置。每次启动和停止均须明确确认，普通打开或轮询状态不启动程序。

启动返回 manager UUID 与 starting 观察，不等于 Native 已就绪，更不等于获得批次权限。停止仅接受该 UUID，等待实际关闭；不能按 PID、URL、进程名或旧历史接管。配置或资源失配时旧 ready 不再有效，但原 UUID 仍可显式停止。关闭面板只停止 UI 轮询，不停止后台 worker；配置、安装和已有实例探测在自有 lifetime 结束前锁定。窗口打开且观察活跃时约五秒读取一次状态，不自动重发启动或停止。

未知清理终态阻止后续启动和宿主退出，不以 owned=false 代替实际关闭证明，也不删除或切换固定 Native gate。正常及浏览器宿主退出均先关闭新批量接纳，再并行等待批量服务与自有 worker；任一收口未确认就保留等待。浏览器 profile 的 Native gate 仍未开放，不因本段加入私有 scope。

设置文件损坏时完整状态读取仍会报错；已有页面保留的原 UUID 可停止，宿主退出收口也不依赖读取设置。重载后不猜测 UUID、不自动恢复能力；独立只读恢复入口尚未实现。

安装只允许用户核对并确认的、已存在且无符号链接的确切 `Mod` 目录。不扫描其他用户目录。没有安装标记、文件已被手动修改或有多个新旧插件目录时，保留现状并提示人工处理，不补写标记强行接管。

「预览安装计划」冻结来源摘要、目标归属与文件指纹，展示版本、增删改和备份位置。计划五分钟过期，配置或资源变化后失效。再次显式确认才执行；更新备份放在 Mod 外，执行前后重新核验实际文件。安装不启动或重启 FreeCAD。最终结果未知时原计划已消费，不自动重试，须重新检测文件与运行连接。

## 正式 MCP 只读探测

从冻结资源中运行自有 Node stdio 子进程，执行固定 MCP `2025-11-25` 初始化、工具发现和两个只读工具 `get_capabilities` / `get_connection_status`。同时核验 MCP Node、清单、运行插件版本及桥接协议；不把一次 HTTP ping 或 `--check` 输出当作 MCP 握手。

仅传递必要的操作系统环境及本机桥接参数，不继承 Node 注入钩子、凭据或反向 Desk 工具配置。累计输出、单消息和诊断有上限，协议检查及清理升级有时限，不保留原始诊断或文档数据，不重试。取消只向自有 Node 探测子进程发起清理，绝不终止 FreeCAD；探测 Promise 与资源租约仍须等到该子进程实际 `close` 才结束。配置变更、资源变更、迟到或过期观察不再显示为连接就绪；检查与安装互斥。

检查结果是一次性观察，不维持连接，也不等同实例发现。界面成功显示「上次 MCP 检查通过（非持续连接）」；发起新检查或遇到异常后不会回退到旧成功状态。后端观察最多复用 30 秒；再次需要实时证明时须用户显式检查。

## 配置与缩略图位置

机器相关的 MCP 模式、确切 Mod 目录和端口保存在宿主用户数据目录的 `freecad-mcp-settings.json`，不写入工程或公开仓库。损坏、不兼容或不安全的配置报错，不静默覆盖。保存使用版本比较与私有临时文件原子替换。

Desk 当前保存独立的显式端口，不自动读取或写入 FreeCAD 用户级共享配置中的 `bridge.preferred_port`；需用户核对两端一致，默认值不是发现结果。显式 MCP 探测传入 `PHOENIX_FREECAD_URL` 优先，既不枚举其他端口，也不改共享配置或重启运行中的桥接。

自动缩略图使用**当前工作空间** `.phoenix/thumbnail-cache/<SHA-256>.png` 与既有数据库登记，不默认写到 `assets`。文档复用的 PNG 属于用户主动导出，另选目录；原有归档图片不自动迁移或删除。未来批处理第一阶段只更新外部 PNG / 缓存，不自动保存 CAD。内嵌 FCStd 缩略图及原 CAD 保存是另一项明确授权的写操作。

## 后续门禁

- 设置控制目前仅为宿主显式开启的候选；后续须将版本化动作接入现有批量任务调度器，不能由连接测试外推正式部署或批量接线已经完成。
- 同一专用 FreeCAD 串行处理明确文件；只关闭自有文档，取消停止后续项，不把未知写入重放。
- 已新增的严格 PNG 校验、元数据边界、源指纹及数据库与缓存发布实现须继续验收支持范围，不能直接复用仅检查 PNG 头部的旧路径。当前 worker 仅支持明确授权的可信原生自包含文件，外链装配和更多工作台类型不自动纳入。
- 实际 FreeCAD 安装、重新加载、跨平台进程退出和独立样件批次验收另列；合成单测与中性 MCP peer 通过不等于原生流程通过。
- 扩展视觉与支持范围；新固定候选已补验明确 Visibility 的独立无 GUI 样件，但不能外推 Body、装配、外链或任意工作台类型。不得用显示全部对象掩盖原始可见性，也不把格式正确的全隐藏白图算作视觉通过。

### 批量动作接线前置（设计约束，尚未实现）

缩略图需要显式的新版本计划及 worker-job 账本，复用现有 `BatchTaskService` 的接纳、持久队列、取消、历史和监控，不新增第二套队列。默认 V2 只读效果不能扩大；V3 保存 BRep 试点不打开完整文档、不写业务缓存，也不能充当缩略图权限。

运行前冻结明确文件清单、源 SHA/bytes、资源与配置摘要、固定渲染 profile 和图片尺寸；在 render 前持久记录 task/run/step/plan digest 与 manager、worker/session/job 身份。连接超时后只查询或明确取消原身份原任务，不更换 ID 再渲染，不从历史观察恢复进程能力。关闭页面只停止 UI 观察，不能取消后台；服务退出则先封新接纳，再等待调度器及自有 worker 收口。

单个 worker 作业以文档已关闭、相机已恢复和同身份 ready 为复用证明，不能套用 V3「每个动作一个进程、实际 close 才成功」的 attempt 语义。整个 worker lifetime 仍持有现有固定 Native gate；动作不能嵌套申请同 gate，也不能切换命名空间。

PNG 安装与工作空间 DB 登记、批次 DB 的 finishStep 不是一个跨库事务。若图片已经发布但批次确认丢失，应记录 unknown 并只读核对既有源、图片及发布回执，不能重新 render 或重复 publication。备份只恢复历史数据，不恢复 worker、租约或旧计划授权。以上状态、恢复及支持范围验收完成前，批量动作继续保持未开放。

全隐藏状态与渲染失败须另行呈现。白色 PNG 本身既不能证明可用缩略图，也不能证明模型为空；不能为了出图强开隐藏对象。现有发布原语只验证 PNG、来源及绑定，未来动作仍须补领域结果分类，不从格式校验继承视觉正确保证。

API 前缀为 `/api/freecad-mcp`，提供 `GET /status`、`PUT /settings`、`POST /install/preview`、`POST /install/apply`、`POST /connection/check`、`POST /instance/start` 和 `POST /instance/stop`。start 在候选门禁满足且显式确认后返回 202 观察；stop 实际收口后返回 200 观察，清理未确认返回 `owned_worker_close_unknown` 503。默认 start 仍阻止。输入有 JSON 大小和字段白名单，不接收命令、脚本、可执行文件、发行资源路径或任意 URL，不提供任意作业执行接口。

## 本轮验证范围

管理能力阶段使用独立构造的临时资源、插件、目录、配置及 stdio peer 覆盖资源摘要/许可、修改安装拒绝、旧受管目录迁移、计划过期/重复执行、未知写入不重放、配置往返变化、并发互斥、MCP 协议及自有进程退出屏障。该阶段的 Registry 与 Local Wing 定向测试、双端类型、Web/Server 构建、文档/架构/依赖边界检查通过。隔离空工作空间页面核验了设置 Header、Primary、实际 Ribbon 共用入口、默认专用模式检查明确阻止和缺资源禁用安装；这些管理能力点检未安装实际插件、运行 FreeCAD 或修改 CAD。

worker 开发候选另有定向测试覆盖固定四工具协议、自有 session、超时后原任务查询与显式取消、实际关闭前保留资源，以及严格 PNG 和外部缓存发布边界。使用保存 GUI 可见状态的两份独立原生样件，已走通同一 worker 连续渲染、外部 PNG 原子发布、数据库登记和既有图册读取；17 项检查覆盖非空白及不同几何图像、源字节保持、取消后原任务终态、staging 清空、两个自有 ChildProcess 先后实际关闭与资源租约保持。两张图已分别目视核对。该范围不包含无 GUI 状态兼容、正式部署、队列接线或跨平台验收。

设置管理控制另以真实路由、真实管理器和独立私有配置完成 15 项原生联验：只读无启动、默认禁用、确认与重复启动保护、同身份 ready、stop 响应前两个自有 ChildProcess 实际关闭、关闭时冻结资源仍在且随后释放、同 UUID 停止仅读观察、退出 admission 关闭以及相关源码指纹保持。该联验未连接在服 HTTP 服务、未打开 CAD 或安装用户 Mod，MCP 设置文件未创建；原生位置解析按现有规则只读本机偏好。它不代替实际窗口人工验收或批量接线。

管理控制阶段冻结源码的 MCP、资源、PNG 发布及关闭相关定向回归，Registry/LOCAL 各 395 项通过，另两项需显式资源的候选测试默认跳过；Web 控制定向各 54 项通过。双端类型、Web/Server 构建、文档、架构与精确依赖边界通过。此为定向验收，不宣称全仓 CI、跨平台、实际窗口人工点检或正式发布通过；最终历史及实际发行包隐私门禁仍另验。

早先无 GUI 状态样件的结构及缓存检查通过，但两张图全白；这一负例保留为未通过的视觉验收，不被后来的 GUI 正例覆盖。所有原生产物、图像、摘要和逐阶段回执只留在仓库外的私有测试目录。联验只向独立测试进程注入固定资源，不改变在服配置或用户 CAD。

### 新固定候选的独立对照（2026-11-06）

新旧候选均为 0.3.2、86 项完整白名单；Node bundle、启动脚本、许可和公共四工具 DTO 字节保持。新候选只向独立测试进程注入，未覆盖旧资源或在服配置。已重跑原有 17 项渲染/缓存联验、15 项管理控制原生联验，均通过。

另由独立 GUI 进程保存两种可见几何、真实 FreeCADCmd 生成四份显式 true/false 文件，再从自有 GUI 样件构造严格限定的对照。11 个同 worker 作业、56 项检查通过，覆盖可见图非空、隐藏状态保留、缺失/非法 Visibility 失败后仍可复用、原任务查询、源字节保持、staging 清空及两个自有子进程实际 close 前保留资源。只对可见项执行六次发布：五条 Gallery 行与每次 worker/session/job、源和图片摘要的发布记录逐项核对，既有 reader 与实际缓存文件一致；隐藏项和拒绝项没有登记，不能用内嵌缩略图回退冒充缓存成功。

有 GUI 时保留已有外观，无 GUI 时使用原生默认材质。因此本轮两类图片色调不同，并非逐字节一致：对应几何的前景轮廓一致；删除 GUI 状态的盒体与真实 Cmd 盒体采用同一默认材质，PNG 字节一致。可见图已分别目视核对，三个全隐藏白图仅证明隐藏语义保留，未作为有效缩略图验收或发布。

前两次测试器失败回执原样保留：第一次是 QA parser 未识别合法瞬态/空依赖/空映射元数据；第二次是错误地要求 GUI 材质与无 GUI 默认材质图片字节相同。修正测试规则后使用全新样件、身份和回执重跑，不覆盖原记录，不把它们归因于候选渲染失败。测试器仍只接受单个独立 Shape，不开放任意工程修复。

新增纯 QA 样件转换器定向各 54 项；连同已有 MCP、PNG 发布、控制和关闭测试，Registry/LOCAL 各 449 项通过，另两项显式候选测试默认跳过；双源 Server 全量类型检查通过。精确远端细分错误目前会被客户端归一为 `worker_remote_error`，本轮证明拒绝和安全终态，不宣称已在 UI 展示精确原因。更多类型、正式部署、批量版本化接线与外观/导出其它功能仍单独验收。

候选联调另有显式门禁：`PHOENIX_FREECAD_MCP_CANDIDATE_TEST=1`，同时提供上述本地清单和固定摘要后运行 `candidate.integration.test.ts`。默认测试跳过此组，不隐式查找或下载制品。该组使用当前真实资源 loader、冻结安装器 dry-run、管理 API 和 bundled MCP 入口，只对独立临时 Mod 与随机端口的中性假桥运行；核验默认专用模式不访问假桥、正式握手只触发 `get_status`、错误协议拒绝，未执行实际安装或 FreeCAD。它不替代真实插件加载、Native 生命周期及正式发行验收。
