## 实现要点

| 路径 | 说明 |
| --- | --- |
| `useDrawingBomReadonly.ts` | 文案、`openSourceModel`、`editSubTabLabel` |
| `DrawingBomReadonlyBanner.vue` | `el-alert` + 来源路径链接 + 「打开模型」 |
| `FileDetailPage.vue` | Tab 上方横幅；动态 Tab 标签 |
| `FileAttributesPanel.vue` | 标题/工具条与只读禁用（写入、推荐、去改名） |
| `FileOverviewPanel.vue` | 快捷区「打开模型」优先、「查看属性」文案 |
| `PartKeyDetailPage.vue` | 图纸行「查看属性」→ `subTab: edit` |

后端 `bom_readonly` / `bom_source_rel` 逻辑不变（`bom_apply_service.load_bom_preview`）。

---

## 用户路径

1. 树或零件详情打开 `*.Drawing.FCStd` → 顶部蓝色提示 + 「打开模型」  
2. 属性字段只读；需改 BOM 时点「打开模型」进入 Link 源 FCStd 的「编辑属性」  
3. 无 `bom_source_rel` 时提示检查 App::Link / 同目录模型，仍禁止写入

**结论**：Web 文件详情与规划 §4.4 对齐；零件详情入口补齐。
