# CAD 批量动作接入清单

Owner：Desk Tools maintainers

点检日期：2026-10-20

先接批量采集和检查，再接缓存、导出，最后逐项接修改与修正。复用已有领域算法，不重写所有工具；一个页面有批量功能，不代表它已经接入统一任务队列。

主目录已有错误修正、属性写入、名称统一、关联文档同步、总成标签、图册、图纸、两类格式转换和编号查重十个工具入口。T1b 在 T1a 五个只读动作上增加 `cad.geometry-cache`、`cad.name-audit`，共七个动作；V2 服务、备份协议和管理页已按文件名单接入主目录。其它领域工具仍保留原流程，不能作为已接入统一队列的 action 展示。验证范围见任务书分期回执。

2026-10-20 的后续依赖、合入策略及物性/高级出图边界见 [CAD 后续能力实施规划](CAD后续能力实施规划.md)，MD 兼容见 [CAD 伴随文档兼容规划](CAD伴随文档兼容规划.md)。

## 已接入的只读动作

下列七项均已注册。它们不写 CAD、不启动 Native、不扫描目录或跟读外链。

| 动作 | 数据和底层 | 边界 |
| --- | --- | --- |
| `file.metadata` | 大小、后缀、SHA256 | 64 MiB 普通文件；相对路径、拒绝符号链接、前后身份一致 |
| `file.text-stats` | UTF-8 行数、字符、词数 | 2 MiB；拒绝二进制/无效 UTF-8，不保存原文 |
| `cad.saved-properties` | 复用 `readCadObjectInfo`，保存的标签、属性和材料字符串 | 保留文件及内部 Name 身份；不跟随外链、不打开 FreeCAD、不写 CAD、不计算质量 |
| `cad.saved-links` | 同一 reader 的 XLink 路径/显示标签列表 | 保序保重复；标签可能缺省回退宿主 Label，不代表目标名称。不查目标、不证明数量或完整 BOM |
| `cad.saved-drawing` | TechDraw 保存类型及页面/视图/尺寸对象数量 | 未投影的页面关联、模板、可编辑文本和几何引用明确为 unknown，不等于原生校核 |
| `cad.geometry-cache` | 指定文件的现有尺寸缓存快照 | 只读固定白名单库与精确行，不建库/表、不测量、不访问清单外依赖；保留 missing/unknown/invalid/record，`freshness: unverified` |
| `cad.name-audit` | 完整冻结选择集的文件名身份、重名及可移植碰撞 | 每个 action 实例执行一次整批分析；保留 revision/variant/初稿，不合并、不删除，不代表已保存 PartNumber 或全空间查重 |

V2 当前效果白名单仅为 `read_file`、`read_cache`、`write_task_db`。结果写任务库；缓存只读租约会创建/释放自己的临时协调锁，不回收已有锁，不能称为文件系统零写入。缓存中的 hash/stamp 是历史来源信息，不据此证明当前 CAD 或依赖 SHA 新鲜。

### T1c 单文件任务库试点

主目录已接入独立 V3 `cad.saved-shape-measurement`，仅由 host 显式注入，冻结单一 file+node 的保存 BRep；默认注册仍是上述七项，Web 对 V3 仅只读展示。该动作声明 `read_file`、`run_native_readonly`、`write_private_temp`、`write_task_db`，只写自有临时数据和任务账本，不写 CAD、业务缓存或产物。

独立样件的正常、取消、超时及实际关闭后再次运行通过；只证明保存形状坐标系的单实体边界盒和体积，不证明参数新鲜度、文档坐标、Body、装配或多文件。材料 UUID 只作未解析元数据，密度与质量仍为空。schema3、迁移与限定双真源回归见[任务书回执](../platform/统一批量任务管理任务书与实施规划.md#t1c-任务库单文件试点回执)。

## 下一批优先采集和检查

| 能力 | 当前可复用部分 | 接入边界 |
| --- | --- | --- |
| 属性与材料缺项报告 | `readCadObjectInfo`，已有保存属性采集 | 区分缺失、空值、来源冲突；多个候选对象不擅自选择写入对象，材料字符串不当密度 |
| 链接实例采集 | `fcstdLinkInstances` | 校验有界 XML；保留宿主文件/对象及目标对象，不能按目标文件去重 |
| 外链缺失与歧义报告 | `buildCadLightDiagnostics`、既有问题分析 | 查找候选目录须纳入预览；收集保存引用不等于已经证明目标存在，不按距离取首个修复 |
| Rigid/Joint 窄诊断 | `readFcstdAssemblyState` | 缺失或异常为未知，不默认刚性；不表示同步或求解健康 |
| 已有缩略图与缺图检查 | `readFileThumbnail` | 缺图是 missing；先保存存在性、格式及来源，不向任务库存大 data URL；实际图片走有界读取 |
| 进一步的静态图纸事实 | 有界 XML 专用投影；首期先交付类型计数 | 模板/页面关联等结构尚不在首期 DTO，须补投影后接入；不证明引用有效，不隐式扫描全空间 |

材料牌号与物性分开；边界盒不是 PNG 像素、最小包围盒或毛坯。质量需有效体积、明确密度与单位，未知不记零；总成需真实实例数量与缩放，另行验收。

静态图纸事实不等于原生图纸校核。当前图纸校核 HTTP 入口强制原生检查，需作为单独的 Native 动作；XLink 分析、编号查重及 STEP 预览也有保存偏好的副作用，不能原封不动注册为仅写任务结果的只读动作。

## 缓存与派生输出

这些任务适合批量，但会写业务数据库、缓存或输出文件，应在预览中单独声明。V2 新增的 `read_cache` 只授予已有缓存查询，不授予缓存更新、Native 或输出写入；不能仅增加一个 Adapter 就开放其它效果。

| 能力 | 当前基础 | 接入前要补 |
| --- | --- | --- |
| 缩略图缓存更新 | 图册提取/复用已有图片 | 抽出显式 files[]，禁止 product 递归扩域；记录缺图及来源，会写 DB/图片缓存 |
| 通用尺寸重测与缓存更新 | `geometrySnapshot`、`readGeometryBatch`；单文件保存 BRep 已单独试点 | 试点不更新缓存；Body、依赖、文档坐标、多文件及缓存写入继续独立验收，不嵌套图册 job |
| CAD 索引刷新 | 已有完整/部分可用索引流程 | 整批维护或末尾屏障，只执行一次；解析失败与遍历/一致性失败分别处理，不能统一忽略错误 |
| 图册 PNG 与 A4 输出 | 已有图册导出/打印能力 | 所选范围、来源新鲜度、显示选项和输出位置固定；写文件导出与交互式浏览器打印分开 |
| 离线 BOM 与检查报告 | 离线交付、编号查重 CSV | 复用完整性与防覆盖规则；BOM 当前按交付契约取快照，不把任意购物车集合包装成完整总成 BOM；不接远程推送 |
| STEP → FCStd | 既有 FreeCADCmd 转换 | 明确每个输入/输出、引擎版本、超时、取消、目标已存在规则；源 STEP 不改内容 |
| SolidWorks → STEP | 既有 Windows COM 导出 | 宿主须具备 Windows/SolidWorks；串行资源、进程归属与退出另验，无引擎时明确不可用 |
| 原生图纸校核与新稿 | 现有图纸执行器 | Native 环境、模板、依赖和参考资料冻结；新稿防覆盖，源 3D 不写，成功与人工审核分开 |

## 修改源文件逐项接入

| 能力 | 接入门槛 |
| --- | --- |
| 属性、PartName、标签 | 冻结真实目标 Name/实例、原值和来源，保留领域 CAS/备份与覆盖规则 |
| 属性计数修正 | 只改已证明不一致的结构计数，不改业务字段；使用同一 XML writer 与写后复查 |
| 改名及关联图纸/引用 | 全批授权范围包含入向宿主，唯一目标、指纹、冲突证明；不自动重做发布不确定项 |
| 缩略图重新生成 | 隔离 GUI、备份/CAS/最终验证，不改用户 GUI 持久偏好；不是缓存读取 |
| 既有图纸精确修正 | 复用已验执行器、冻结计划、源保护、取消及最终 ZIP 重开；只由一个调度器拥有 |
| 链接路径修正 | 不按 basename/距离猜接；精确宿主对象、歧义人工、最终重开 |
| Rigid 更新和 Joint 修正 | 暂无安全通用写 API；不往返翻转、不删除 Joint、不猜接子元素 |

首期不开放任意属性写、自由脚本或远程执行。新增 Adapter 先声明效果、身份、取消和核对策略，不因统一按钮而降低领域门槛。

普通文档关联改名仍复用通用改名执行器，规则链、文件/目录/内容联合计划及授权目录保持原契约，不逐个文件盲替换。普通改名不自动备份、不新增确认弹窗的既有约定不被统一管理器改变；CAD 写入沿用各领域已声明的保护策略。

## 暂不自动化的能力

- **Rigid 与 Joint 自动修正**：先做保存状态和明确失联端报告；没有经验证的同步方法前，不自动翻转 Rigid、不删除 Joint、不猜接子元素。
- **体积、密度、质量和重心**：当前没有可直接接入的完整批量物性服务。先开发有效最终实体与单位化计算；密度未知则缺失，不能从材料牌号或边界盒猜质量，总成还需真实实例数量与缩放。
- **按外观猜直径和高度、最小包围盒、毛坯尺寸**：与现有 XYZ 边界盒区分，保留后续识别需求，不混入首轮测量。
- **任意修复脚本、自动删对象、自动合并重复件**：无白名单、精确计划及验收边界时不开放；人工审图和交互式选对象仍在原 View。

## 接入顺序和调度

1. **先验证已有只读闭环**：在独立合成文件上使用文件信息、文本统计和已保存 CAD 属性，检查排队、刷新、取消、失败继续与历史恢复。
2. **继续静态报告**：T1b 七动作、V2 file/batch 目标及 schema/备份迁移已按名单集成；后续保存属性缺项、链接实例、Rigid/Joint、静态图纸事实和已有缩略图仍只读所选文件。候选查找需要额外范围时单独预览授权。
3. **扩展有限试点**：保存 BRep 单文件测量已落任务库；通用尺寸重测、转换及图纸检查继续补各自范围、资源、归属与取消。缓存更新、一次索引刷新、报告/图册/BOM 输出分别声明新效果，不继承试点权限。
4. **试点受控写入**：优先选择一项已有验收基础的图纸精确修正，完整验证后再接属性、标签、改名、缩略图重生及链接修正；物性赋值和装配更新另做专项。

V2 采用 action-major 顺序：按保存的 action 实例顺序串行；文件动作在该实例内按冻结文件顺序执行，batch 动作每实例只执行一次并覆盖全部冻结输入。预览分别显示 file/batch 步数、ready/blocked/not_applicable，不再用文件数乘动作数推算。改名与入向引用修正仍须全批依赖计划；未来组合读写先预检，再完成已授权修改，最后读取最终数据并归并刷新缓存/索引，不沿用只读阶段顺序代替写入规划。

每项至少记录文件/宿主/内部 Name、动作及版本、输入指纹、状态、结果来源和失败原因。独立安全项失败后继续；未知写入或共享依赖错误阻止受影响下游。错误进入 Bottom 并显示日志，后台状态以 DB 为准，关页、停靠和动画不改变运行状态。

维持本地 SQLite 加单服务 worker，不引入 Redis、分布式队列、任意 DAG 或失败写操作自动重放。V2 已增加 file/batch scope 和冻结资源；实例输入、受控写效果及输出账本仍按真实动作扩充。MVC 与版本化契约保留，不先做远程执行。

## 代码核对入口

主目录对应的代码位置：工具导航 `web-ui/src/composables/cadBatchTools.ts`；保存属性 `server/src/features/cad-object-info/`；静态引用 `server/src/lib/fcstdLinkIdentity.ts`；刚柔性与关节 `server/src/lib/fcstdAssemblyState.ts`；缩略图 `server/src/lib/fcstdThumbnail.ts`；尺寸与图册 `server/src/features/part-gallery/`；图纸 `server/src/features/drawing-batch/` 和 `drawing-research/`；写入与改名分别在 `fcstdBatchAttributes.ts`、`fcstdPropertyRepairService.ts`、`cad-name-normalize/` 和 `cad-assembly-labels/`。

T1a/T1b 原验收保持；本轮 T1c 的实际 Native 仅限独立构造的保存 BRep 单文件试点，未访问生产 CAD。旧原生入口同 gate 接线仅有 mock 生命周期回归，不代表实际 STEP、缩略图或图纸重新验收。真实工程路径、样件明细及精确回执保留在仓库外或已忽略目录；图纸 D0c 不因命名修正而注册为统一只读动作。
