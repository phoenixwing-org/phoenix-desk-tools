## 结论

`AssemblyTreeTable.vue` 的行渲染已提炼为单消费者 `AssemblyTreeRowGroup.vue`。父组件从第一切口后的 1,030 行降到 517 行；RowGroup 为 618 行，拥有主行、多实例附加行、五列单元格和行级 scoped style。

这次只移动视觉责任，没有改变公开契约、懒加载、写盘或 XLink 替换语义。`AssemblyTreeTable` 仍是装配树唯一 Page shell；RowGroup 是无独立状态的受控渲染组件，不是第二个装配树 Controller。

## 责任边界

```text
API / AppShell / XlinkReplaceDialog
               ↓
AssemblyTreeTable（展开、懒加载、编辑 Map、公开契约）
               ↓ 受控 props
AssemblyTreeRowGroup（TR / TD / 行样式）
               ↑ toggle / label-input / open-file / replace-xlink
assemblyTreeViewModel（UI-neutral 纯投影）
```

| 层级 | 保留责任 |
| --- | --- |
| `AssemblyTreeTable` | 7 个公开 props、5 个公开事件、6 个 `defineExpose` 方法；API、Shell、替换弹窗；树展开、多实例展开、懒加载、编辑 Map 和 apply patch 投影 |
| `AssemblyTreeRowGroup` | 10 个受控 props；`toggle`、`toggle-instances`、`label-input`、`open-file`、`replace-xlink` 五类语义事件；行 DOM 与行级样式 |
| `assemblyTreeViewModel` | 递归扁平化、行状态、实例投影、标签比较、规则预览和 pending patch 等纯函数 |

RowGroup 只以 `import type` 引用 `AssemblyTreeNode` 契约；运行时不导入 API，不读取 Shell、Dialog、Pinia、storage，也不建立 `ref` / `reactive` 状态。父组件继续是公开组件，调用方无需感知 RowGroup。

## 冻结的公开契约

- props：`nodes`、`loading`、`editable`、`treeDepth`、`xlinkReplace`、`labelEdits`、`savingLabels`，默认值保持不变。
- events：`edits-change`、`need-full-depth`、`xref-replaced`、`discard-label-edits`、`apply-label-edits`。
- `defineExpose`：`getPendingPatches`、`getPendingLabelChanges`、`hasEdits`、`resetEdits`、`expandAllTree`、`applyRuleLabelsPreview`。
- 主实例输入框 key 继续使用 `node.id + host_repo_rel/xlink_file_attr` 的既有组合；标签编辑不会因行组件迁移而串到另一实例。

## DOM 与样式约束

- RowGroup 以 Vue fragment 输出相邻 `tr`；`tbody` 的直接元素只能是 `TR`，不得插入组件包装 `div`。
- 主行和多实例附加行都保持五列：链接标签、目标文件、数量、状态、操作；只读或禁用替换时按既有条件隐藏/禁用内容。
- 父组件拥有 table、thead、toolbar、空状态和列宽 CSS 变量；RowGroup 消费同一组变量并拥有 `td` padding、border、背景与行内容样式。
- 表头继续 `position: sticky`；表格滚动留在 `.table-scroll`，页面外层不得因窄宽度产生横向溢出。

## 人工点检清单

以下项目需要连接真实 CAD 工作区；Browser 夹具不会伪造通过。每项填写“通过 / 失败 / 跳过”，失败时附工作区、文件相对路径、日志和截图。

- [ ] 在“文件详情 → 引用”打开包含子装配的真实 FCStd，首屏标签、文件、数量、状态、操作五列与改造前一致。
- [ ] 展开已有 children 的子装配，再展开需要懒加载的子装配；不重复请求，不串节点，失败时仍显示既有 Host 状态提示。
- [ ] 在“第一级”数据上点击“全部展开”，Host 切到全部层级后能继续展开，而不是在 RowGroup 内私自加载第二份树。
- [ ] 对多实例分别修改两个标签；“放弃”完全复原，“应用”产生正确的 host/xlink patch，重新打开后结果一致。
- [ ] “按规则填标签”预览只修改可编辑行，规则为空、值未变化和缺失引用的统计与改造前一致。
- [ ] 缺失和歧义行的“改链接”打开正确宿主的 Dialog；应用后刷新装配树并上抛一次 `xref-replaced`。
- [ ] 压缩页面高度后纵向滚动到最后一行；约 360px 宽度下横向滚到“操作”列，表头、工具栏和页面外层不跟随表格横滚。
- [ ] 真实工作区点检期间无 Vue warning、未处理 Promise、重复 key 或无效 table 结构告警。
