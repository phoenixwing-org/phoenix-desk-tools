# 零件图册需求

为试制、采购、销售和开发提供可按产品查看、打印和归档的零件图片清单。全工作空间复用一份零件缩略图缓存，选择产品总成后，只展示该产品实际引用的零件。第一版以只读提取 FCStd 内嵌缩略图为主，不修改 CAD 文件。

## 范围与入口

- 新增独立「零件图册」View，可从 CAD 工具和文件详情进入。
- 支持全库浏览和指定产品总成浏览。第一版以所选总成文件标识产品，不另建正式产品主数据表。
- 产品范围沿实际装配引用递归展开，包含跨目录的标准件和旧版本引用；不将同目录所有文件混入产品。
- 同一源文件在图册中去重；不同版本、不同文件不可仅凭同名合并。子总成单独标识，可筛选是否展示。不把识图清单冒充数量已核对的采购 BOM。

## 卡片与打印

每张卡片显示简短类别、图片、零件号及版本、零件名称；普通零件类别显示「一般件」。网页紧凑网格随可用宽度增加列数，类别叠放在图片左上角，毫米尺寸位于图片右下方，不占用图片布局空间。图片下方编号与名称左右排列，宽度不足时自动换行。名称优先用源零件 PartName；缺失时使用现有文件名解析规则，不从上层实例标签反推。按一般件、标准件、其他类别分组，组内按零件号和版本自然排序；未知类型不猜测。

卡片与打印显示零件主实体或总成物理实例的文档轴对齐外包络 X × Y × Z（mm），不是 PNG 像素尺寸，也不是加工公差尺寸；不排序轴长、不推断直径。无法安全确定主实体、总成结构或依赖，空形状和独立图纸显示「尺寸未获取」并提供原因。圆柱/圆环「直径 × 高度」识别留在 TODO，当前不实现。

提供前端关键词及类别筛选、缺图状态和文件详情链接。网页卡片提供标签、尺寸、零件号和文件名显示开关：前三项默认勾选，文件名默认隐藏；选项随页面会话保存，点击图片始终可进入文件详情。A4 预览同步当前筛选与显示选项，纵向四列五行，类别叠在图片左上、尺寸叠在右下，编号与名称同行并可换行，卡片不跨页；支持浏览器打印并另存 PDF。打印隐藏工具栏、侧栏和悬浮操作，保留产品、页码或分页标识和数据生成时间。内嵌浏览器未提供原生打印窗口时，可下载带内嵌图片的独立打印页，在系统浏览器打开后打印；此下载不代表 Git 归档。

## 数据和文件归属

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| 工作空间 SQLite 缓存表 | 源相对路径、文件指纹、零件字段、缩略图状态及尺寸、缓存更新时间 | 可重建的快速查询，不成为 CAD 属性真源 |
| 工作空间本地缓存目录 | 按指纹保存的 PNG | 全库复用，避免每次卡片显示都解压 FCStd |
| 用户明确指定的工作空间内 Git 目录 | 同源文件名 PNG | 明确纳入 Git 的图片资源，数据库记录归档关联 |
| 用户可选的文档归档 | 相对路径清单 JSON、独立 HTML 图册 | 用户主动勾选才随图片导出，默认不归档文档 |

PNG 去掉 `.FCStd` 后改为 `.png`，默认稳定路径为 `assets/thumbnails/<源一级目录>/<同名>.png`；根目录模型直接放在 `assets/thumbnails`。不带时间、不保留更深的模型目录，方便其他文档复用。相同图片复用；同名、大小写或归属冲突拒绝覆盖。已登记且未被外部修改的旧 PNG 可更新，更新前备份到本地 `.phoenix/thumbnail-archive-backups`。旧快照目录保留，不自动迁移或删除。Git 归档的主要对象是 PNG，文档是否归档由用户决定，勾选后在独立 `documents/<快照>` 中保存 HTML/JSON，引用稳定 PNG。在线查看与打印无需先归档。不自动暂存、提交、推送或上传，不改 `.gitignore`。可选归档清单仅含相对路径，不泄露机器绝对路径。图片只是最后一次保存在源文件中的视图，不能保证最新几何或统一视角。

## 缓存和进度

显式更新可批量为索引中的 FCStd 建立缓存；按产品更新只处理其引用范围。相同文件指纹复用元数据和图片，搜索排序不重新读 CAD。逐文件显示进度及成功、缺图、失败计数；单文件失败不冒充全体成功。源文件变化后更新缓存；已删除文件不得继续作为有效结果。无内嵌图显示「缺少缩略图」，不生成虚假模型图。

2026-11-06 范围失效修正：产品成员与全局图片缓存分别管理。每个范围独立保存有版本的源指纹和引用快照；不能用另一范围或单件操作更新过的全局图片行证明旧成员仍有效。日常读取核验路径和独立快照，新增、变更或旧版无证明的来源只读解析当前保存的 XML；不写库、不启动 Native。已移走、删除或解除引用的旧条目不再作为当前卡片或批次输入；真实断链保留相对路径诊断，不按编号、版本或 basename 猜新路径。全库仍只以现有索引为种子，过期的 present 路径也须通过磁盘核对；新路径需更新索引或从当前总成实际引用发现。

「更新图片缓存」重新读取当前引用与源内容哈希，只复用可验证的图片；最终再次复核后，在同一事务发布当前范围成员、范围证明和文件行，报告解除的旧成员数量。其他范围、共享 PNG、历史归档和 CAD/备份均保留，不做全库清空或物理图片垃圾回收。取消、源变化、闭包读取不完整或可确认的事务回滚不替换原范围；提交回执未知时明确要求只读核对，不自动重跑。待确认范围禁止打印、归档、加入批次和尺寸 Native 读取，仍可更新缓存。读取中只隐藏旧成员不等于已经删除数据库记录。

源文件不存在、当前引用断链、CAD 存在但 PNG 损坏/缓存缺失分别处理。单件重新生成在 Native 门禁前核对真实源及依赖；缺失时给刷新索引/图册或修复链接的提示，不把文件系统绝对路径直接显示为错误。卡片重新激活只加载缓存，不自动渲染；当前缓存任务可取消，尺寸任务不借用此取消权限。图册更新仍只提取保存的图片，不承诺图片代表最新几何。

本轮 Registry/LOCAL 各 333 项自动回归通过（Server 290、Web 43），覆盖改名、移动、解除引用、共享缓存、旧索引、旧缓存证明、真实断链、PNG 损坏、取消/变中/事务回滚/提交回执丢失，以及重载失败和迟到预览。只用独立样例，未主动重启在服服务或操作实际工程库、CAD、备份。用户随后确认刷新正常；该反馈仅作为刷新验收，不扩展为所有断链、原生测量、打印或总成尺寸验收。

CAD 索引单文件解析失败时，正常文件仍可建立「部分可用」索引，图册使用状态为 present 的正常资产；失败文件单独标记，不混入有效图册范围。扫描清单、失败数量和原因可在 CAD 索引页与 Bottom 日志核对，BOM 明确不完整。目录遍历失败、符号链接、扫描中文件变化、取消、数据库版本或写入冲突仍中止提交；不通过跳过这些问题伪装完整索引。

默认排除各级点开头的文件夹、`node_modules` 和 `__pycache__`；点开头的文件名本身不受此目录规则影响。图册读取同时过滤旧缓存中的排除目录记录，完整索引更新在原事务内移除新增排除范围的派生关系、标记旧资产为 ignored，保留文件、资产身份、人工关联与审计，不执行全库重置。

## 安全与技术边界

只读 CAD，不调用 FreeCAD 重算或保存。ZIP 大小、解压、XML 和图片尺寸设限；引用和缓存路径不得越出当前工作空间或穿过符号链接。缺失引用、循环、超限和解析失败显式提示。复用 Wing 的 XML、属性和引用解析能力；Desk 负责 View、缓存和归档适配，不复制 CAD 领域算法。

公开文档与测试使用独立构造的通用样本，不使用或改名复刻私人产品、结构或几何。真实工程检查与图片仅保存在授权的本地私有位置。

## 实现记录（2026-10-05）

入口为「批量工具 → 零件图册」，装配文件详情也可带上下文打开；路由 `part_gallery`。直接在主库 Web 联调，不改依赖绑定、不操作 CAD 保存。

Desk 适配层位于 `server/src/features/part-gallery` 与 `web-ui/src/features/part-gallery`。复用 Wing 属性、文件名及 XLink 解析；缩略图 ZIP 提取、路径防护、文件 I/O、SQLite 缓存及打印展示留在 Desk，不作为新的公共 CAD 规则。

SQLite 复用工作空间 `.phoenix/phoenix-workspace.sqlite`，只新增 Desk 所有的缓存表：

| 表 | 关联键与用途 |
| --- | --- |
| `desk_cad_thumbnail` | 源相对路径主键；属性、源指纹、图片 SHA-256、PNG 像素宽高、状态及引用文件缓存 |
| `desk_cad_geometry` | 源相对路径主键；主实体毫米边界盒、源/依赖指纹、算法版本与更新时间，独立于图片状态 |
| `desk_cad_gallery_scope` | 产品相对路径主键；空字符串表示全库，保存更新时间、提示和独立版本化 `sources_json` 范围证明；旧表在显式更新时补列，GET 不迁移 |
| `desk_cad_gallery_member` | 产品路径 + 源路径；按产品的文件集合，不保存采购数量 |
| `desk_cad_thumbnail_archive` | 导出相对路径主键；关联源文件与图片指纹 |

图片缓存位于 `.phoenix/thumbnail-cache/<SHA-256>.png`。图册和文件详情优先读取 SQLite 登记且散列正确的归档 PNG，再回退内部缓存；源文件指纹未变时不重新解压 CAD。缺少有效 PNG 时，显式更新可重建缓存；未登记图片不凭同名冒充缓存。归档校验所选源文件散列及每个输出文件的 Git 忽略状态。同路径 PNG 采用归属/散列保护及写前备份；不改 Git 暂存区。

API 前缀 `/api/cad/part-gallery`：GET `options`、`catalog`、`thumbnail`、`jobs/:id`；POST `jobs`、`jobs/:id/cancel`（仅图片缓存任务）、`geometry-jobs`、`document`、`archive`。工作空间隔离，提取与尺寸操作各自限制单工作空间一个任务，前端互斥；上限 5000 文件，PNG 4 MiB / 4096×4096，打印内嵌图片总量 64 MiB。产品是文件引用范围，不包含工作空间外部依赖，不能等同对象级 BOM。

主库本地真实样本完成卡片与 A4 预览检查，私人编号、路径、缩略图及明细不写入此文档或测试。自动样本独立构造，仅表达去重、循环、缺图及路径安全条件。正式发布仍需执行产品 TODO 中的全量隐私门禁。

点检：本地 Wing 消费端 Server 全量 70 个测试文件 / 334 项通过；新增安全项之后图册专项 6 项通过。Web 全量 89 个测试文件 / 621 项通过（Registry 与本地 Wing 均执行）。本地 Wing Web/Server bundle、架构检查、依赖边界和文档检查通过。Web 用临时类型 resolver 指向本地 Wing 声明时类型检查通过；标准类型检查仍受既有未发布 Wing 页签导出的 Registry 版本差异影响，不把临时 resolver 当作正式依赖升级。

### 总成外包络首轮（2026-11-06）

总成继续复用图册「更新尺寸」，无须另建任务。服务端确认唯一 `Assembly::AssemblyObject`、`App::Part` 或 `App::LinkGroup` 根及完整工作空间内 FCStd 依赖，原零件缓存算法 v1 保持可复用，总成使用独立算法 v2；不把旧零件盒当作总成尺寸。

测量范围为保存结构中的物理组件/实例，不依赖 GUI 隐藏状态；重复实例按各自位姿保留，Body 作为叶实体，不遍历其历史草图与特征。原点、基准、关节和草图等辅助对象不扩大包络。逐实例以官方 `Part.getShape(root, subname, transform=True, retType=1)` 解析实际形状及归属，不能再次叠乘返回矩阵；原生 AssemblyLink 使用自身派生成员路径，不假设其刚柔变换等同普通 App::Link。

实际形状组成 Compound 后优先 `optimalBoundingBox(False, False)` 读取较紧的轴对齐包络；仅方法不支持时回落标准 BoundBox，并保留固定方法说明。不是布尔融合、重新网格化、最小有向盒搜索、装配求解或 Rigid 切换，也不重复对每个实例做完整 BRep 拓扑有效性分析。不用旋转局部盒的八角合并冒充精确结果。

保存 XML 与恢复对象的成员、链接目标和位姿不一致，源/依赖变中，缺失目标，未知物理结构或超限时不给整体尺寸。原生 AssemblyLink 还须对照源总成的物理定义成员及重数，拒绝派生 Group 的少项/多项；该检查不是最新关节、求解或派生位姿同步证明。结果只描述已保存/恢复的实例状态，不保证参数几何已经重算，需修正装配时使用独立维护流程。

限制每模型最多 500 个依赖文件、2000 个物理实例、64 层、10000 次结构访问；每次隔离读取仍最多 100 个文件、2 分钟。当前不把 Link-array 当作已验证的普通重复 Link，遇到这类未支持结构保留「暂无法完整确认」原因，不断言源文件损坏。日常浏览只读缓存，文件或依赖变化后失效。复杂模型仍可能超时，不承诺固定耗时或毫米级制造精度。

独立验收：Registry/LOCAL 各 246 项专项通过（Server 图册 200、手工 Native 验证脚本静态/安全测试 3、Web 43），双源类型检查、Web/Server 构建、依赖与架构边界通过。FreeCAD 1.1.0 / OCCT 7.8.1 的固定标准门禁下，12 个合成正例覆盖旋转、嵌套、刚柔混合、重复实例、隐藏对象、远辅助及跨文件 XLink；3 个负例覆盖缺失目标和派生成员少项/全空。生产读取与官方逐物理实例包络一致，独立解析几何按官方累计矩阵复核，最大误差约 4.5×10⁻⁸ mm；不能把它当作实际模型精度保证。15 例生产读取含启动/加载约 0.40 秒，单例几何均为小样件；不是大工程性能承诺。源文件、保存/恢复与测量前后位姿/状态均未变化，跨文件唯一根和依赖预检也通过。样件、原始回执和指纹留在仓库外，未操作实际工程库或用户 FreeCAD；真实工程交互验收仍待用户显式更新尺寸。
