# 零件图册需求

为试制、采购、销售和开发提供可按产品查看、打印和归档的零件图片清单。全工作空间复用一份零件缩略图缓存，选择产品总成后，只展示该产品实际引用的零件。第一版以只读提取 FCStd 内嵌缩略图为主，不修改 CAD 文件。

## 范围与入口

- 新增独立「零件图册」View，可从 CAD 工具和文件详情进入。
- 支持全库浏览和指定产品总成浏览。第一版以所选总成文件标识产品，不另建正式产品主数据表。
- 产品范围沿实际装配引用递归展开，包含跨目录的标准件和旧版本引用；不将同目录所有文件混入产品。
- 同一源文件在图册中去重；不同版本、不同文件不可仅凭同名合并。子总成单独标识，可筛选是否展示。不把识图清单冒充数量已核对的采购 BOM。

## 卡片与打印

每张卡片依次显示图片、零件号及版本、零件名称。名称优先用源零件 PartName；缺失时使用现有文件名解析规则，不从上层实例标签反推。按自制件、标准件、其他类别分组，组内按零件号和版本自然排序；未知类型不猜测。

提供前端关键词及类别筛选、缺图状态和文件详情链接。默认 A4 纵向、多行三列卡片，卡片不跨页；支持浏览器打印并另存 PDF。打印隐藏工具栏、侧栏和悬浮操作，保留产品、页码或分页标识和数据生成时间。内嵌浏览器未提供原生打印窗口时，可下载带内嵌图片的独立打印页，在系统浏览器打开后打印；此下载不代表 Git 归档。

## 数据和文件归属

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| 工作空间 SQLite 缓存表 | 源相对路径、文件指纹、零件字段、缩略图状态及尺寸、缓存更新时间 | 可重建的快速查询，不成为 CAD 属性真源 |
| 工作空间本地缓存目录 | 按指纹保存的 PNG | 全库复用，避免每次卡片显示都解压 FCStd |
| 用户明确指定的工作空间内 Git 目录 | 同源文件名 PNG | 明确纳入 Git 的图片资源，数据库记录归档关联 |
| 用户可选的文档归档 | 相对路径清单 JSON、独立 HTML 图册 | 用户主动勾选才随图片导出，默认不归档文档 |

PNG 去掉 `.FCStd` 后改为 `.png`，默认稳定路径为 `assets/thumbnails/<源一级目录>/<同名>.png`；根目录模型直接放在 `assets/thumbnails`。不带时间、不保留更深的模型目录，方便其他文档复用。相同图片复用；同名、大小写或归属冲突拒绝覆盖。已登记且未被外部修改的旧 PNG 可更新，更新前备份到本地 `.phoenix/thumbnail-archive-backups`。旧快照目录保留，不自动迁移或删除。Git 归档的主要对象是 PNG，文档是否归档由用户决定，勾选后在独立 `documents/<快照>` 中保存 HTML/JSON，引用稳定 PNG。在线查看与打印无需先归档。不自动暂存、提交、推送或上传，不改 `.gitignore`。可选归档清单仅含相对路径，不泄露机器绝对路径。图片只是最后一次保存在源文件中的视图，不能保证最新几何或统一视角。

## 缓存和进度

显式更新可批量为索引中的 FCStd 建立缓存；按产品更新只处理其引用范围。相同文件指纹复用元数据和图片，搜索排序不重新读 CAD。逐文件显示进度及成功、缺图、失败计数；单文件失败不冒充全体成功。源文件变化后更新缓存；已删除文件不得继续作为有效结果。无内嵌图显示「缺少缩略图」，不生成虚假模型图。

## 安全与技术边界

只读 CAD，不调用 FreeCAD 重算或保存。ZIP 大小、解压、XML 和图片尺寸设限；引用和缓存路径不得越出当前工作空间或穿过符号链接。缺失引用、循环、超限和解析失败显式提示。复用 Wing 的 XML、属性和引用解析能力；Desk 负责 View、缓存和归档适配，不复制 CAD 领域算法。

公开文档与测试使用独立构造的通用样本，不使用或改名复刻私人产品、结构或几何。真实工程检查与图片仅保存在授权的本地私有位置。

## 实现记录（2026-10-05）

入口为「批量工具 → 零件图册」，装配文件详情也可带上下文打开；路由 `part_gallery`。直接在主库 Web 联调，不改依赖绑定、不操作 CAD 保存。

Desk 适配层位于 `server/src/features/part-gallery` 与 `web-ui/src/features/part-gallery`。复用 Wing 属性、文件名及 XLink 解析；缩略图 ZIP 提取、路径防护、文件 I/O、SQLite 缓存及打印展示留在 Desk，不作为新的公共 CAD 规则。

SQLite 复用工作空间 `.phoenix/phoenix-workspace.sqlite`，只新增 Desk 所有的缓存表：

| 表 | 关联键与用途 |
| --- | --- |
| `desk_cad_thumbnail` | 源相对路径主键；属性、源指纹、图片 SHA-256、尺寸、状态及引用文件缓存 |
| `desk_cad_gallery_scope` | 产品相对路径主键；空字符串表示全库，保存更新时间和提示 |
| `desk_cad_gallery_member` | 产品路径 + 源路径；按产品的文件集合，不保存采购数量 |
| `desk_cad_thumbnail_archive` | 导出相对路径主键；关联源文件与图片指纹 |

图片缓存位于 `.phoenix/thumbnail-cache/<SHA-256>.png`。图册和文件详情优先读取 SQLite 登记且散列正确的归档 PNG，再回退内部缓存；源文件指纹未变时不重新解压 CAD。缺少有效 PNG 时，显式更新可重建缓存；未登记图片不凭同名冒充缓存。归档校验所选源文件散列及每个输出文件的 Git 忽略状态。同路径 PNG 采用归属/散列保护及写前备份；不改 Git 暂存区。

API 前缀 `/api/cad/part-gallery`：GET `options`、`catalog`、`thumbnail`、`jobs/:id`；POST `jobs`、`document`、`archive`。工作空间隔离，单工作空间只允许一个提取任务；上限 5000 文件，PNG 4 MiB / 4096×4096，打印内嵌图片总量 64 MiB。产品是文件引用范围，不包含工作空间外部依赖，不能等同对象级 BOM。

主库本地真实样本完成卡片与 A4 预览检查，私人编号、路径、缩略图及明细不写入此文档或测试。自动样本独立构造，仅表达去重、循环、缺图及路径安全条件。正式发布仍需执行产品 TODO 中的全量隐私门禁。

点检：本地 Wing 消费端 Server 全量 70 个测试文件 / 334 项通过；新增安全项之后图册专项 6 项通过。Web 全量 89 个测试文件 / 621 项通过（Registry 与本地 Wing 均执行）。本地 Wing Web/Server bundle、架构检查、依赖边界和文档检查通过。Web 用临时类型 resolver 指向本地 Wing 声明时类型检查通过；标准类型检查仍受既有未发布 Wing 页签导出的 Registry 版本差异影响，不把临时 resolver 当作正式依赖升级。

## 后续能力

统一视角和高分辨率缩略图需独立调用 FreeCAD 渲染，另行确认耗时、进程隔离及失败恢复。后续再增加正式产品登记、物料数量核对、选定零件生成试制模板及服务器端直接 PDF 导出，不阻塞第一版浏览器另存 PDF。
