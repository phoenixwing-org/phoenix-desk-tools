## 流程

```
用户改名 FCStd 文件
  → DB 查询：谁引用了这个文件 (fcstd-query ✅)
  → 扫描 Document.xml 中的 XLink file 属性
  → 修改 XLink 指向新文件名
  → 写回 FCStd ZIP
```

## 原生方案

| 步骤 | 实现 | 状态 |
|------|------|------|
| 查引用关系 | Rust fcstd-query (SQLite) | ✅ |
| 读 XML XLink | Rust fcstd-reader | ✅ |
| 改 XML XLink | Rust fcstd-xlink (新 crate) | ⬜ |
| 写回 FCStd ZIP | Rust fcstd-reader write.rs | ✅ |
| 编排逻辑 | TypeScript cad.ts | ⬜ |
