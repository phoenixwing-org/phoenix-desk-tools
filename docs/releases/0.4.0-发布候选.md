# Phoenix Desk Tools 0.4.0 发布候选

状态：release candidate（macOS 已验收，Windows 待验收）

Owner：Desk Tools release maintainers

适用版本：0.4.0

最后核验：2026-08-17

## 版本结论

本轮采用 `0.4.0`。相对 0.3.0，本轮包含 Workspace Gate、Welcome / Workbench 分离、
Wing Workbench Home、统一主题、最近工作空间与信息 Block、Dockable Tool，以及 Web / Tauri
共用后台发现等用户可见能力，不属于仅修复缺陷的 `0.3.1` 范围。

根清单、Web、Server、Tauri config、Cargo package / lock 和 Windows 发布门禁统一使用
`0.4.0`。历史 0.1.0 / 0.2.0 制品和验收回执不改写。

## 主要变化

面向用户的完整变更列表见仓库根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

- 无工作空间时由 Wing `PnwWorkspaceGate` 显示全屏 Welcome；打开、关闭、返回和刷新恢复统一进入现有 Workspace controller。
- Welcome 的最近使用、项目与运行方式、贡献与维护为三个同级可折叠 Block；贡献区使用 Wing 信息卡片组，新增贡献者只需追加 JSON DTO。
- Home 成为普通 Workbench View；Welcome 不进入 Tab / MRU。
- light / dark / system 主题、凤凰之翼标志、favicon、选择确认框和 Workspace 类型选择器复用 Wing 公共实现。
- Web 与 Tauri 发现并复用唯一 Desk API；TypeScript 负责 FCStd ZIP/XML、SQLite 与文件查询，Tauri Rust 保持薄壳。
- KT Codegen、Primary、中央 View、Properties 与 Bottom Panel 继续向 VS Code 工作台行为收敛。
